# 데모 보완: 계단실, 추격 모션, 사운드, 전체 한국어 음성

2026-10-09 사용자 피드백: 계단 주변 벽 구멍, 뛰지 않는 귀신, 잘 들리지 않는 사운드, 끝까지 더빙/자막 적용.

## 구현
- 계단실 양쪽을 연속 벽으로 연결하고 천장 높이까지 마감. 2층 앞쪽 복도에서 계단 하단으로 잘못 떨어지는 개구부를 막음.
- 떠 있던 얇은 계단 블록을 바닥까지 찬 구조로 변경. 계단 폭과 참을 측벽에 맞추고 경사 난간과 기둥을 배치. 콘크리트 재질 적용.
- 기존 로컬 귀신 리그에 0.6초 달리기 애니메이션 추가. 팔/무릎 굽힘, 상체 기울기, 발 접지 높이 조정. 추격 이동속도 260cm/s, 달리는 플레이어 350cm/s. 경로가 막히면 애니메이션도 멈춤.
- 사운드 원본을 바탕으로 15개 효과음/환경음의 RMS와 피크를 조정. 벽 차폐 배율 .25 → .65, 저역통과 1100 → 2600Hz, 환경음 재생 배율 .22 → .55. 설정에 전화벨 테스트 버튼 추가.
- Windows 기본 출력 Realtek, 음소거 해제, 시스템 음량 32%, 게임 세션 음량 100% 확인. 시스템 설정은 변경하지 않음.
- 사용자 정정 반영: 실제로 들리는 대화 29줄만 한국어 더빙. 전화, 문 너머 주민 대화, 202호 문밖 목소리가 대상이다. 문서·기록 속 인용문·조사 설명·주인공 독백은 모두 무음이며 자막으로만 표시한다. 전체 33개 이야기 구간의 125줄 자막은 유지했다. 잘못 생성했던 낭독 음원 96개는 최종 에셋과 패키지에서 제거했다.
- 민서 F1, 정숙 F2, 관리자·104호 주민 M2, 문밖에서 들리는 주인공 목소리 M1 프리셋. 모든 음성은 Supertone/supertonic-2 로컬 추론, 실존 인물 복제 없음. 대사 길이에 맞춰 자막 유지. 202호 연출은 대사가 끝나기 전 다음 목소리·침묵 단계로 넘어가지 않음.
- Art/Voice/Day1/manifest.json에 원문/읽는 대사/목소리/길이/해시/모델 출처 기록. Steam Content Survey에는 이 사전 생성 음성 사용을 포함할 것. 모델 라이선스 원문은 Art/Voice/MODEL_LICENSE.txt.

## 재현
1. tools/create_day1_voices.py: 기존 로컬 모델과 numpy/onnxruntime 필요. 없는 남성 기본 프리셋만 공식 모델 저장소에서 다운로드. 결과 WAV/manifest와 Content/Data/voices.json 생성.
2. Blender --background --python tools/create_ghost_run.py: 기존 haedam_ghost.blend에서 별도 달리기 FBX/BLEND 제작.
3. python tools/balance_audio.py: 효과음 원본에서 매번 생성하므로 보정 배율이 누적되지 않음.
4. tools/build.ps1 -EngineRoot <UE_5.8> -ImportPolish -Package
5. tools/verify_polish.ps1: 실제 W 입력 계단 왕복, 뼈대 변화, 125줄 자막 보존 / 29줄 대화만 음원 연결 / 문서 무음, 최종 통화 종료, 사운드 출력 녹음 및 기존 기능 테스트.

## 검증 범위
전체 사람이 수행한 첫 플레이 테스트를 대신하지 않는다. 음성의 감정 연기와 실제 스피커에서의 청감 밸런스는 사용자의 피드백으로 더 조정할 수 있다. 귀신 모델은 기존 프로토타입 모델을 유지했다.

최종 검증: 대화 전용 빌드에서 NRPolishTest, NRFeedbackTest, NRExperienceTest, NRSmokeTest, NRDemoTest, NRChaseTest 모두 failures=0. 미사용 낭독 에셋을 물리적으로 정리한 최종 패키지에서도 NRPolishTest와 NRSmokeTest를 재통과. 계단/달리기 게임 캡처 확인. 게임 마스터 출력 녹음 4.95초, RMS 0.0447, 피크 0.350으로 무음/클리핑 없음. 실제 스피커 청감과 긴 회차의 난이도는 별도 사용자 플레이 피드백이 필요함.

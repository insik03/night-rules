게임 연결 범위

104·105·203·204·208·301호 기존 입주실에 배치. 복도에 충돌 물체를 추가하지 않는다. 대화 시 10도 문틈과 걸쇠를 유지하고 대화 종료·이탈·추격 시 닫는다. 얼굴을 밝히는 별도 조명은 추가하지 않았다.

204·208·301호에 짧은 선택적 인사 대사를 추가했다(새 음성 없음). 민서는 최종밤의 기존 샤워실 구조·대피 상태와 연결했다. 보행·립싱크·새 민원이나 엔딩 조건은 추가하지 않았다.

Blender 동작 표본 실측에서 벽·침대·옷장 명목 영역과 간섭 없음. 준호·아룬은 벽에서 8cm 추가 이격. 이 결과는 실제 게임 충돌 검증을 대신하지 않는다.

# 공포 리듬 수정 — 어두운 문틈, 갑툭튀, 드문 추격

2026-10-12 사용자 요청을 반영한 향후 연출 기준. 현재 실행 파일을 수정한 기록이 아니다.

## 최신 방향

- 문틈은 어두워 상대의 얼굴·눈·입·손을 볼 수 없다. 목소리, 문 움직임, 안전 걸쇠, 실제 재실 맥락으로 판단한다. 정상 대화와 사칭 존재 모두 같은 시각 규칙을 따른다.
- 갑툭튀를 명시적으로 사용한다. 점프스케어를 아예 배제하는 해석은 철회한다. 다만 일상 업무/조사 → 이상한 징후 → 잠시 정적 또는 안도 → 짧은 놀람 → 확인/조사와 회복의 순서로 배치한다.
- 갑툭튀와 추격은 별개다. 한 번 놀란 뒤 대부분은 현장에 남아 확인하거나 물러날 수 있다. 귀신 목격도 대부분 곧바로 달리기 신호가 되지 않는다.
- 추격은 **본편 전체 1~2회**를 초기 배치 목표로 삼고, DAY마다 자동으로 발생시키지 않는다. 이 횟수는 모델의 제안 수치이며 플레이테스트 후 사용자와 조정한다. 데모의 후반 추격을 본편에 유지하면 이 총량의 한 번으로 계산한다. 중반과 옥상에 새 추격을 각각 더하는 방식은 피한다.
- 추격 횟수를 줄여도 위험은 유지한다. 경고를 무시하고 깊이 들어가거나 실제 추격에서 붙잡히면 사망할 수 있다. 갑툭튀가 발생했다는 이유만으로 회피 불가능한 사망을 주지 않는다.

## 배치 후보

| 구역 | 긴장 쌓기 | 짧은 놀람 | 이후 |
|---|---|---|---|
| 사칭 문틈 대화 | 목소리 위치/답변이 어긋나고 대화가 끝남 | 안에서 문짝을 한 번 밀어 걸쇠가 크게 당겨짐 | 얼굴은 계속 안 보임, 자동 추격 없음, 실제 입주민 위치 확인 |
| 공실 조사 | 멀리서 들리던 노크가 멎음 | 출입문 옆 벽이나 빈 침대 프레임에서 갑자기 가까운 충격음 | 원인/흔적 조사, 출구를 부당하게 잠그지 않음 |
| 분리 샤워실 | 사용 흔적이 있는데 물소리가 멎음 | 확인한 빈 칸의 문이 시야 가장자리에서 한 번 닫힘 | 발자국/밸브 상태 조사. 다른 샤워실마다 복제하지 않음 |
| 옥상 | 바람과 빨래 소리 사이에서 실루엣을 의심함 | 시트를 걷는 순간 한 번의 가까운 움직임 | 확인하면 사라짐, 옥상 추격을 별도로 추가하지 않음 |

위 목록은 후보이며 전부 필수 연출로 확정하지 않는다. 놀람마다 같은 큰 소리/문 닫힘만 사용하지 않고, 배치와 소리의 강약을 플레이테스트로 선택한다. 특정 문을 열 때마다 반복되거나 무작위 시간마다 재생되는 형태는 사용하지 않는다. 같은 사건은 한 회차 한 번을 기본으로 하고, 체크포인트 재시도 시 긴 연출/음성 반복을 줄인다.

## 기존 스토리와 연결

- 202호는 기존 갇힘·노크·관리실 각성 흐름을 유지하고 입장 즉시 추격하는 과거 초안으로 돌아가지 않는다. UV/일반 조사로 위험을 알아보고 피할 수 있어야 한다.
- DAY 3 CCTV/사칭 사건의 자동 추격은 제거 대상이다. 이 구간은 목격·갑툭튀·후속 확인으로 압박한다. 이미 데모 추격을 사용했다면 새 중반 추격을 추가하지 않는다.
- DAY 4 구조는 준비한 동선·문 상태·잘못된 접근의 위험으로 처리하고 독립 추격을 하나 더 만들지 않는다.
- DAY 5 통로 개방의 최종 추격은 주요 후보로 유지한다. 기존 데모 추격을 본편에서 빼면 최종 한 번, 유지하면 합계 두 번을 시작점으로 검토한다.
- 추격이 없는 순간에도 소리, 인물 사칭, 문 상태와 놓친 민원의 결과가 계속 불안을 만든다.

## 구현 시 확인

- 문짝/걸쇠 충격 연출 중 문이 몸을 밀어 벽 밖으로 보내거나 플레이어를 가두지 않는다.
- 어두운 문틈은 배치·차폐·실내 조명으로 만들고 손전등을 임의로 고장 내지 않는다. 일반광/UV·밝기 설정·CCTV·플레이어 시점에서도 얼굴 식별이 튀어나오지 않는지 확인한다.
- 얼굴이 안 보인다는 사실은 정상/사칭의 구분 단서가 아니다. 음성/문맥/현장 확인을 대조하는 구조를 유지한다.
- 놀람 사운드는 게임 사운드 설정을 따르고 과도한 볼륨으로만 놀라게 하지 않는다. 연출 직후 음성이 묻히거나 자막이 겹치지 않아야 한다.
- 최종 추격에는 접근 전에 위험 징후와 도주 경로를 제공하고, 사망 체크포인트는 탈출 가능한 상태를 저장한다.

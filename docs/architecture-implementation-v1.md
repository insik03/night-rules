# 해담고시원 건축 적용 v1

> 시안과 일치하는 완성본이 아니다. 사용자가 구조·색감 불일치를 지적했고, [v2 수정 기록](architecture-reconcile-v2.md)으로 후속 수정한다. 아래 이동 검사 통과는 시각적 일치를 증명하지 않는다.

기준은 승인된 `Art/EnvironmentConcepts/v14-fixture-access/floor1-master.png`와 상층 출입 구조다.

## 범위

- 1~3층: 12개 객실 열, 단일 1.3m 복도, 반대편의 주방·화장실·별도 샤워실.
- 1층: 관리실 앞 방 제거, 기존 2.8m 관리실·반벽/반유리·오른쪽 문 유지. 후면 창고의 문 앞은 비우고 선반은 서쪽에 둔다.
- 2~3층: 관리 수납실에서 서쪽 수납방으로 연결. 주방 확장, 식탁 두 개, 샤워실과 화장실 분리.
- 계단: 층당 160cm 상승하는 반 층 계단 두 개, 반 층 계단참, 각 층 같은 복도로 복귀. 3층에서 옥상까지 연결.
- 옥상: 동일 건물 외곽, 계단실, 난간, 처마 아래 세탁 자리, 건조 줄 구조.
- 3층: 화재 후 수리한 밝고 깨끗한 벽·바닥 마감. 307호는 공실.
- 기존 작은 소품은 재배치만 수행. 신규 장식 소품과 새 공포 이벤트는 이번 범위에서 제외.

거주 설정은 층당 5실이고, 조사 공실 3실에는 프레임과 책상만 둔다. 나머지 공실은 비워 둔다. 202호/307호 공실, 민서의 203호는 유지한다. 이번 변경으로 NPC 15명을 새로 제작한 것은 아니다.

## 생성 및 조립

Meshy `image-to-3d` 네 작업이 모두 성공했다. 실제 비용 30×4=120크레딧이며 재생성은 하지 않았다. 원본과 작업 ID는 `Art/EnvironmentMeshy/v1/provenance.json`에 기록했다. 인증정보와 서명 URL을 담은 원본 응답은 Git 제외 경로에 있다.

원본에서 문틀 벽·창문 벽·반복 벽·타일 벽·타일 바닥·외부 계단 6개 메시를 Blender로 제작했다. 문 개구부는 기존 87cm 문틀과 맞추고, 창에는 실제 관통구와 별도 유리를 사용한다. 원본은 수정하지 않는다. 평평한 건축 부품은 원본의 색상을 정확한 닫힌 면에 베이크해 삼각형 갈라짐을 없앴다. 게임용 부품은 12~18,000 삼각형과 2K 텍스처다. 이 보정에는 추가 크레딧을 사용하지 않았다.

`NRArchitecture.cpp`가 실제 게임 조립 기준이다. Meshy 표면과 정확한 벽·문·계단 충돌은 분리돼 있다. 원본에 자동 생성된 삼각형으로 이동 판정을 하지 않는다.

외부 비상계단은 현재 외관 및 층별 진입 난간까지만 배치된 모듈이다. 외부 계단을 연속해서 내려가는 탈출 동선과 사건은 후속 작업이다. 주 이동은 실내 계단을 사용한다.

## 기존 진행 보존

삭제한 뒤 복도에 있던 장부·카트리지·공구함은 1층 관리실 뒤 창고로 옮긴다. 분전함은 1층 복도 끝 계단 맞은편, UV 손자국 점검구는 같은 위치의 2층 벽으로 옮긴다. 진행 안내문도 함께 수정한다.

실제 이미지: `docs/architecture-built-v1.html`. 층별 조감도는 천장을 숨기고 검토용 조명만 추가한 실제 게임 캡처이고, 아래 플레이 시점은 일반 게임 밝기다.

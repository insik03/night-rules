# 해담고시원 데모 플레이테스트

프로젝트 폴더의 `PlayDemo.cmd`를 더블클릭하면 창 모드로 실행한다. 실제 Windows 실행 파일은 `Builds/Windows/NightRulesPrototype.exe`이며 폴더 안의 다른 파일도 함께 필요하다. 이 실행기는 자동 검사 옵션을 사용하지 않는다.

현재는 개발용 데모다. 15~20분의 초행 플레이를 목표로 하며, 목표 시간은 아직 실제 초행 플레이로 검증하지 않았다. 이번 연출 개편판의 정답 경로 자동 진행은 약 11분 35초에 완주했다. 이 수치를 초행 플레이 시간으로 해석하지 않는다.

## 조작

| 키 | 기능 |
|---|---|
| WASD / 마우스 | 이동 / 시점 |
| Left Shift / Left Ctrl | 누르고 달리기 / 누르고 앉기 |
| E | 바라보는 물건 조사, 전화 받기, 문 조작 |
| F | 손전등 켜기 / 끄기 |
| T | 수집한 UV 카트리지 장착 |
| Q | 장착된 카트리지의 UV / 일반광 전환 |
| J | 확인한 기록 다시 보기 |
| Esc | 자료 닫기 / 일시정지 |
| R | 사망·일시정지에서 체크포인트로 복귀; 종료 화면에서는 처음부터 다시 시작 |

처음에는 관리실 안에서 걸려오는 전화를 받는다. 첫 통화가 끝나면 내부를 탐색할 수 있다. 근무 중 현관은 잠겨 있다. 오른쪽 위에 현재 할 일이 표시된다. 이후에는 전화·기록·현장 단서를 이용해 판단한다. UV는 보조 수단이며 필수 카트리지가 없어도 진행할 수 있다.

## 확인할 내용

공략이나 자동 검사 경로를 보지 않고 한 번 진행한 뒤 다음을 기록한다.

- 시작부터 마지막 화면까지 실제 플레이한 시간. 자리를 비우거나 오래 일시정지한 시간은 별도로 표시한다.
- 길이나 다음 행동을 찾지 못해 막힌 장소, 또는 읽기 어려웠던 단서.
- 가장 긴장된 순간, 소리가 너무 작거나 컸던 순간, 추격이 불공정하게 느껴졌는지.

이 결과에 따라 분량과 안내, 추격·사운드 타이밍을 조정한다. 시간을 맞추기 위한 강제 대기나 반복 왕복은 추가하지 않는다.

## 로그

실행 기록은 `Builds/Windows/NightRulesPrototype/Saved/NightRules/actions.jsonl`에 남는다. `tools/summarize_demo_session.py`로 완주 시각·사망·사건 기록을 요약할 수 있다. 자동 검사와 일반 실행은 구별해서 해석해야 하며, 일반 실행 로그만으로 자리 비움이나 실제 체감을 알 수는 없다.

## 이번 플레이 피드백 반영

- 203호와 다른 입주민의 방은 닫힌 채 문밖에서 대화한다. 실제 인간 NPC 모델/풀보이스는 아직 없다.
- 202호 첫 진입에서는 추격하지 않는다. 닫히는 문, 빨라지는 노크, 정적과 암전, 관리실 각성으로 이어진다.
- 관리실 책상에 남은 물건을 조사한 뒤 다음 사건이 진행된다. 이후 민서의 증언이 당시 기억과 모순된다.
- 실제 추격은 후반 재실 확인 뒤 한 번이며, 대사가 끝나고 발소리 전조가 지난 뒤 시작한다. 이때 복도 조명이 점멸한다.
- 일시정지 메뉴에서 계속하기, 체크포인트 복귀, 게임 종료를 선택할 수 있다.

- 관리실 책상 서랍은 E로 열고 닫는다. 왼쪽 맨 위 서랍을 열면 안의 UV 카트리지를 따로 바라보고 E로 줍는다. 닫힌 서랍에서는 획득할 수 없다.

- 하단의 조사 안내·화자·대사는 하나의 세로 영역에 배치한다. 긴 대사는 자동 줄바꿈하며 높이를 고정하지 않아 겹치지 않는다.

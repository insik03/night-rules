# Mac 시연용 최신 게임 공유 — 2026-11-23

이 브랜치는 로컬 제작 프로젝트의 게임 Source와 Content를 함께 공유한다. Mac 지원 도구만 있던 첫 커밋의 한계를 해소하기 위한 스냅샷이다.

## 포함
- 일반광에서는 숨고 UV 조준·거리·잔량·가림 조건에서만 표시되는 손바닥. 202호 표시 면은 26×34cm. 금속 조각은 11×2.5cm 유지, 손바닥 일부만 표시.
- 손바닥을 세 줄로 설명하던 오래된 기록 문구 수정.
- 기존 기어다니기 연출의 깜빡이는 조명 강도 조정(원래 강도의 100%/12%).
- 관리실 책상/개별 서랍 수리, 변기·세면대, 밥솥, 휴지통, 청소 양동이, 옥상 세탁기·수납장·빨래 바구니, 외벽 마감과 창문 개구부. 새 메시·재질·텍스처 47개와 UV 재질 1개는 Git LFS 사용.
- 런타임과 함께 수정됐던 가구 배치 기록 동기화. 이번 공유 작업에서 새로운 방 배치나 치수 설계를 정하지 않았다.
- 기존 주민 6명 등 이미 공유된 에셋 유지.

유료 생성물은 기존에 승인·생성한 에셋이며 이번 작업에서 추가 생성/과금하지 않았다. 책상/서랍은 자체 수리 메시다. 기존 외부 에셋과 폰트의 출처/이용 범위는 team-assets.md 및 ai-assets.md를 따른다. 원본 생성 서비스 응답, 개인 파일, 발표자료, 빌드 캐시는 포함하지 않는다.

## 검증 구분
- 이 게임 수정은 이전 Windows 빌드에서 검증한 파일을 공유한다. 과거 검증: 최근 에셋·건축·조사 검사 성공, 이후 UV/연출 조사 24개 및 score 26개 성공.
- 이번 공유에서는 Source/Content 파일의 로컬 원본 일치, LFS 다운로드 완전성, 저장소·JSON·Python/Bash 검사 및 정적 자산 참조를 확인한다.
- Mac 컴파일·패키징·플레이는 아직 미검증이다. Draft PR 상태로 Mac 시험을 받는다. 본편 2시간/모든 엔딩 QA 완료를 뜻하지 않는다.
- 빌드 후 verify는 NRInvestigationTest, NRScoreTest, NRRecentAssetsTest를 실행한다. 실패 시 Builds/MacVerification 로그와 빌드 오류를 공유한다.

# 에셋과 공개 범위

공유 시작: 2026-11-12. 기존 개발 폴더의 원본 Git 이력은 공개 저장소에 복사하지 않았습니다. 개인 서류와 임시 서비스 응답이 뒤섞이지 않도록 현재 작업 파일에서 새 공유 기준을 만들었습니다.

## 포함
- 게임 Source / Config / Content / Fonts 및 필수 도구.
- 자체 제작 메시·텍스처·사운드, 승인된 AI 생성 에셋, 제작 원본과 도면.
- Poly Haven/ Kenney의 CC0 에셋. 각 원본의 라이선스 기록 유지.
- Nanum 폰트 및 OFL 문서.

## 제외
- 엔진 바이너리/캐시/시연 빌드, 개인 제출 서류, unrelated 웹사이트, 녹화 원본과 백업.
- 계정/서명 다운로드 응답, 서비스 로그, 미사용 오디오 서비스 실험 폴더.
- 개인 설치된 외부 AI 스킬 묶음. 프로젝트 기준 문서와 원본 출처 목록은 유지.
- 제외 자료는 기존 제작 폴더에 보존되어 있습니다.

## 다운로드
기본 LFS 다운로드는 게임 Content입니다. Art 원본은 담당자가 해당 경로만 추가로 받습니다. LFS 저장·다운로드 사용량은 저장소 소유자 계정에 누적됩니다. 자동 과금/요금제 변경은 하지 않았습니다.

## 프로젝트 권리
이 저장소의 공개 설정만으로 프로젝트 전체에 재사용·판매·재배포를 허용하는 오픈소스 라이선스를 부여하지 않습니다. GitHub 이용약관에 따른 기능과 개별 외부 자료의 원래 라이선스는 그대로 적용됩니다. 팀원이 프로젝트 작업을 위해 사용하는 범위와 외부 에셋의 조건을 구분하세요.

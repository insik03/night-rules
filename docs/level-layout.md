> 최신 공간 배분(2026-10-12): 휴게공간은 1층에만 둔다. 2·3층은 확장 주방과 식탁 각 3개, 출입문 반대편 조리대/냉장고를 계획한다. 상층 화장실은 계단 쪽으로 옮기는 안이다. 최신 이미지는 `Art/EnvironmentConcepts/v5/`, 상세 수정 기록은 `single-corridor-plan-v2.md` 참고. 게임 반영 전 이미지 검토 단계다.

> 후속 요청: 기존 좁은 주 복도를 유지하고 두 줄 복도를 정리한 [수정안 v2](single-corridor-plan-v2.md)를 작성했다. `floor-plan.html`은 이제 현재 구현 비교가 포함된 **검토용 수정안**이며, 실제 게임 반영 완료를 뜻하지 않는다.

> 2026-10-12 사용자 최신 결정: **현재 게임의 좁은 복도와 작은 방을 유지**한다. 아래 v0.2의 4m 복도·층당 6실은 과거 기록이며 현행 구현이나 새 제작 기준이 아니다. 현재 주 입주실 복도는 명목 130cm, 방 피치 230cm/깊이 300cm, 층당 12실이다. 전체 건물은 1~3층 + 4층 높이의 옥상으로 구상하되 기존 공간을 넓히지 않는다. 맵·모든 소품은 제작 전 이미지를 먼저 보여주고 확인받는다. 옥상 세탁·건조/사건 활용 및 전체 확장 초안은 [building-masterplan-v1.md](building-masterplan-v1.md) 참고.

- 1층 입구 바로 앞에 배치한다.
- 입구가 보이는 벽면은 아래쪽 절반이 벽, 위쪽 절반이 유리창이다. (사용자 최신 수정)
- 출입문은 유리 정면이 아닌 옆면에 둔다.

- 문 옆 접근 공간은 관리실 내부 면적에 포함하지 않는다.
- 본편의 관리실도 이 기준을 따른다. 대형 사무실이나 별도 침실로 확장하지 않는다.

## 출입구와 외부 시야

- 현관은 관리실 정면 유리창 맞은편에 둔다. E로 열고 닫으며 실제 외부 바닥으로 걸어 나갈 수 있다.
- 외부는 가로등과 인접 건물이 보이는 작은 야간 골목이다. 현재는 프로토타입 범위이며 전체 도시를 구현하지 않는다.
- 2층 복도 끝과 202·203호의 외벽에는 벽을 실제로 비운 창문을 설치한다.
- 창문 밖에 외부 배경이 보여야 한다. 불투명한 벽 위에 창문만 붙이는 방식은 사용하지 않는다.

## 전체 평면 v0.2

- 주 복도와 뒤쪽 복도는 각각 폭 4m로 게임 동선 검증을 우선한다. 실제 건축 재현 폭으로 확정한 값이 아니다.
- 각 층에 6개 입주실, 공용주방, 화장실·세면 공간, 휴게공간을 구성한다.
- 왼쪽 통로와 관리실 옆 통로가 주 복도와 뒤쪽 복도를 연결한다. 주방과 휴게공간도 양쪽 복도로 통한다.
- 관리실 옆문은 x=140 벽을 따라 연속되는 통로에 면한다. 독립된 움푹 패인 전실을 두지 않는다.
- 오른쪽 계단은 1층 주 복도에서 올라가 2층 뒤쪽 복도로 연결된다.
- 202·203호는 2층 주 복도 쪽에 유지한다. 방 사이 틈은 벽으로 채우고 바닥·천장·외벽·창문을 함께 만든다.
- 추격은 방 밖에서도 이어진다. 귀신은 연결 경로를 따라 이동하며 닫힌 문과 벽은 통과하지 않는다. 현재는 1층으로 내려가면 추격에서 벗어난다.
- docs/floor-plan.html에서 층별 평면을 확인한다.

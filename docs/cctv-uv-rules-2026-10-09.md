# CCTV · UV · 조항별 붉은 글씨 수정 (2026-10-09)

## 플레이 변경

- CCTV 두 카메라에 주인공의 임시 몸체가 렌더링된다. 이동 속도에 따라 팔다리가 움직이며, 앉으면 몸체도 낮아진다. 1인칭 화면에는 몸체가 끼어들지 않는다. 최종 캐릭터/애니메이션 에셋은 별도 제작 대상이다.
- 두 번째 카메라를 202호보다 앞쪽으로 옮겨 첫 조사가 화면 안에 들어오도록 했다. 최근 60초 녹화와 선택한 프레임의 고정 재생은 유지한다. CCTV를 열고 있는 동안 플레이어 이동은 잠기므로, 복도를 걸은 뒤 관리실로 돌아와 되감기로 확인한다.
- `T` 카트리지 장착 → `Q` UV 전환 → 대상을 비춤 → `E` 흔적 기록 → `J` 다시 읽기. 카트리지는 켜진 UV를 사용하며 움직일 수 있을 때만 45초를 소비한다. 일반광·꺼짐·일시정지·확대 문서 열람 중에는 소비하지 않는다.
- 202호 손잡이 옆 벽: ‘안에서 잠김 / 손잡이 없음’과 세 줄의 표시가 드러난다.
- 악몽 후 관리실 책상의 손잡이 조각: 같은 세 줄을 UV로 확인한다. 두 흔적을 실제 조사한 경우에만 대조 기록이 추가된다. 조각부터 보더라도 아직 확인하지 않은 202호 표식을 알고 있는 것처럼 설명하지 않는다.
- UV는 260cm 이내, 조명 방향 안, 벽에 가려지지 않은 대상에만 작동한다. 문 앞에서 UV 모드만 켜 놓고 단서를 받던 동작을 없앴다. 자원이 없어도 일반 조사를 통해 스토리가 진행된다.
- UV는 작성자/진실 여부를 자동 표시하지 않는다. 규칙이 가리키는 물건의 흔적을 조사하는 도구다.

## 사용자 의도 반영: 특정 규칙을 두고 충돌하는 글씨

DAY 1에서는 **2번 ‘공실에서 소리가 나도 문을 열지 마십시오’**를 대상으로 한다. 첫 통화를 끝낸 뒤 관리실에 있을 때 이 조항 바로 아래에 **‘이 규칙은 거짓말입니다.’**가 나타난다. 규칙표를 3.5초간 살펴보면 같은 줄 옆에 **‘아니야, 믿지 마!’**가 추가된다. 폰트·크기·색상은 동일하다. 작성자를 UI로 구분하지 않는다.

벽의 규칙표와 E로 확대한 문서가 같은 단계의 문구를 표시한다. 확인한 반박은 J 기록과 체크포인트에 남는다. 규칙 번호와 두 문구는 `Content/Data/day1.json`의 `rule_annotation`에서 관리하며, 벽 텍스처는 `tools/create_rules_display.py`로 다시 생성한다.

## 검증

- `NRInvestigationTest`: 실제 CCTV 픽셀에서 몸체 표시 여부, 이동과 다리 자세 변화, 선택된 녹화 프레임 보존, UV 방향/차폐/전원/잔량 조건, 두 단서의 대조, 무음 문서, 붉은 글씨의 순차 등장과 체크포인트 복원.
- `NRSmokeTest`, `NRExperienceTest`, `NRFeedbackTest`, `NRPolishTest`: 모두 통과. 130줄의 자막을 유지하며 더빙은 기존 실제 대화 29줄뿐이다.
- `NRUVPreview`, `NRUVFragmentPreview`, `NRRulesReplyPreview`: 렌더링 화면 검토용. 일반 규칙표는 `NRRulesPreview`.
- 최종 Windows 패키지: `Builds/Windows`. 사용자 입력 설정 변경은 그대로 보존한다.

## 에셋 / 재현

UV 원본은 `tools/create_uv_marks.py`로 생성한다. `tools/import_investigation.py`로 UV 마스크 텍스처, 임시 몸체용 재질, 규칙표 3단계 텍스처를 가져온다. `tools/build.ps1 -EngineRoot <UE_5.8> -ImportInvestigation -Package`로 재생성한 텍스처까지 패키지에 반영한다. 임시 몸체는 엔진 기본 도형으로 구성했고 외부 캐릭터 에셋이나 새 음성은 추가하지 않았다.

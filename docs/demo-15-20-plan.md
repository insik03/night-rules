# 15~20분 공개 데모 제작 상태

사용자 목표: 15~20분 플레이, 다양한 사운드와 소등 이벤트, 탐색·귀신 목격·추격·사망. 가능하면 Claude 협업.

## 현재 사건 흐름

1. 필수 첫 전화, 관리실 내부 탐색. 통화 완료 후 문 해제.
2. 203호 문밖 대화 → 202호 조사. 닫힌 문과 가속되는 노크, 정적, 암전 후 관리실에서 깨어남. 이 장면에는 추격이 없다. UV는 보조 단서.
3. 관리실에 남은 손잡이 조각을 조사하면 정전. 초반 조사 시간을 제한하는 210초 정전 및 시간제 귀신 출현은 제거.
4. 주방 예비 퓨즈 → 1층 뒤편 계단 근처 분전함. 실제 조명 차단/복구, 가까운 숨소리, 위층 발소리.
5. 청소 선반 점검 장부와 공용 세면대 열쇠표 비교 → 관리실 PC 첫 보고.
6. 관리자 전화. CCTV 전원을 끄고, 105호/203호 재실 확인과 2층 뒤편 봉인 점검을 수행. 장비를 끈 지 60초 후 다시 켤 수 있으며, 그동안 탐색 가능.
7. 두 번째 203호 방문에서 기억을 뒤집는 증언. 대화와 발소리 전조 뒤 한 번의 실제 추격. 죽으면 사건 직전 체크포인트로 복귀.
8. CCTV 복구 기록과 모순되는 증언을 PC에 보고 → 307호 마지막 전화 → 데모 종료.

## 공포 연출

위치·사건 기반 일회성 점멸, 의자 긁기, 정전, 천장 발소리, 배관 노크, 가까운 숨소리, 금속 진동, 재입실 시 관리실 문 닫힘(다시 열 수 있음), 봉인 점멸과 노크, 후반 한 번의 추격. 반복 환경음은 낮은 볼륨으로 간격을 두고 재생한다. 202호 암전 후 관리실로 장면이 전환된다. 그 외 탐색 시점은 플레이어가 조작한다.

12개 원본 합성 WAV. 4개 실제 공간 환경음 컴포넌트. 거리 감쇠와 가림/저역 필터 적용. 사운드 연출의 최종 청감 품질은 추가 검토 필요.

## 검증 기준과 미완료

- 컴파일·Windows 패키지·상태 테스트만으로 15~20분을 증명하지 않는다.
- 전체 동선을 실제 이동/상호작용으로 수행하고 진행 막힘, 단서 접근성, 자연스러운 첫 회차 시간을 기록해야 한다.
- 단순히 종료 타이머를 15분으로 잠그는 방식은 사용하지 않는다. 현재 빠른 경로가 목표보다 짧다면 사건/읽기/탐색의 밀도를 개선해야 한다.
- 음량/소리 반복/공포 타이밍 및 정전 시 손전등 가독성, 추격 중 문·장애물 상태를 실제 실행에서 확인해야 한다.
- 기존 기능 테스트는 체크포인트와 이벤트 상태를 검증하며 인간 플레이의 재미나 실제 플레이타임을 대신하지 않는다.
- 현재 15~20분 목표 달성은 **미검증**. 출시 완료로 표시하지 않는다.

## Claude 협업 상태

로컬 Claude Code 2.1.267에 범위가 분리된 사운드 생성 작업을 요청했으나 API 403: 조직에서 Claude Code 구독 접근 비활성화. 요청은 모델 추론 전에 거절되었고 Claude가 생성한 변경 사항은 없다. 계정 정책을 우회하거나 API 키를 구입하지 않았으며 Codex가 구현을 계속했다.

## 실제 입력 동선 검사 — 진행 중

- `tools/verify_demo_walk.ps1`은 패키지에 `-NRDemoWalk`를 전달한다. `Content/Data/demo-walk.json`의 105단계를 W/E/Esc 입력과 시점 회전으로 진행한다. 순간이동, 사건 시계 변경, 아이템 지급, 직접 상호작용 함수 호출은 하지 않는다.
- 문서 읽기에는 정해진 읽기 속도를 사용하므로 **초행 플레이 시간의 증거가 아니다**. 로그 요약은 이 실행을 `automated_known_route`로 구별한다.
- 1차: 관리실 메모 조준이 모니터에 가려짐. 메모를 책상 앞쪽으로 이동했고 2차 실행에서 실제 E 입력으로 읽기 통과.
- 2차: 첫 전화 → 관리실 자료 → 2층 → 202호 진입 → 첫 추격 탈출 → 정전 → 퓨즈 수집 → 전원 복구까지 통과. 이후 선반 위 장부가 선반 모서리에 가려져 정지했다. 관측된 조준 대상은 `shelves`, 충돌 높이는 약 154.6cm였다.
- 장부를 선반에 세운 형태로 수정했고 3차 실행에서 실제 E 입력으로 읽기 통과.
- 3차: 세면대의 단순 충돌 영역이 수도꼭지와 상판 사이의 빈 공간까지 막아 열쇠표 대신 세면대를 선택했다. 충돌 높이는 약 95.5cm. 이동 충돌은 그대로 유지하고 상호작용 광선만 실제 삼각형 표면을 사용하도록 수정했다. 퓨즈·장부·열쇠표를 서 있는 눈높이에서 조준하는 검사를 추가했다.
- 전체 경로 재검증은 아직 필요하다. 실패 기록은 `tools/output/demo-walk-note-blocked.log`, `tools/output/demo-walk-ledger-blocked.log`, `tools/output/demo-walk-sink-blocked.log`에 남겼다.
- 수정 빌드: NRDemoTest 21개(눈높이 조준 3개 포함), NRSmokeTest, NRChaseTest, 정전 화면 생성 검사 통과. 추격 검사는 16초 시점의 생존을 요구하던 불안정한 기준 대신, 25초 이내 실제 우회 추적과 사망을 모두 확인한다(`routed=1 caught=1`). 전체 입력 경로와 초행 플레이 시간은 여전히 별도로 검증해야 한다.

## 전체 동선 도달 및 사운드 보완

- `f1763ff` 기반 실행은 105개 입력 단계와 마지막 전화까지 630.8초(약 10분 31초)에 도달했다. 사망 없이 두 번 추격을 탈출했고 정전·퓨즈·두 보고·CCTV 복구를 진행했다. 그러나 결과 출력 직후 자동 검사 타이머의 캡처를 해제한 뒤 다시 참조해 종료 충돌이 발생했다. 이 실행을 정상 종료까지 통과했다고 표시하지 않는다. 기록: `tools/output/demo-walk-completed-exit-crash.log`.

- 최신 빌드의 NRDemoTest 21개, NRSmokeTest(노크 순서·일시정지·자료 확대 중 타이밍 정지 포함), NRChaseTest, 정전 화면 검사는 통과했다.
- 자동 경로의 10분 31초는 초행 15~20분의 증거가 아니다. 실제 첫 플레이의 시간과 막힌 장소, 사운드 체감은 [플레이테스트 안내](demo-playtest.md)에 따라 확인해야 한다.

## 2026-10-09 플레이 피드백 반영

사용자가 기존 PRD의 퀘스트 HUD 최소화 원칙을 변경했다. 현재 할 일을 오른쪽 상단에 한 가지 표시하며 정보의 진위나 신뢰도는 표시하지 않는다. Shift 달리기, Ctrl 앉기, 별도 일시정지 메뉴, 닫힌 문을 사이에 둔 입주민 대화, 추격 중 복도 점멸을 추가했다. 아래 이전 검증 이력의 두 번 추격과 시간은 구버전의 기록이다. 개편판 빌드·검증 결과는 이어서 기록한다.

책상 상호작용: 기존 Poly Haven CC0 책상의 본체와 원래 서랍 6개를 Blender에서 분리했다. 원본 UV와 재질을 유지하며 서랍은 38cm 슬라이드한다. 왼쪽 위 서랍 안의 카트리지는 개폐 및 체크포인트 상태에 따라 보이거나 숨겨지고, 개방 시에만 획득 가능하다.

자막 수정: 조사 안내와 자막을 각각 고정된 하단 위치에 그리던 방식을 단일 세로 레이아웃으로 교체했다. 화자/대사/상호작용의 높이는 내용에 맞춰 결정하고, 긴 문장에는 자동 줄바꿈과 어두운 배경을 적용했다. Unreal 에디터의 실제 게임 화면에서 1280×720 및 960×540 긴 대사 표시를 확인했다.

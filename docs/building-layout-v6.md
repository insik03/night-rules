# 해담고시원 — 샤워 분리·빈방 조사·입주민 배분 v6

> 실제 구현 후속: 승인된 v14를 바탕으로 Meshy 부품 4종(실사용 120크레딧)을 생성하고 Blender 보정 후 3개 층과 옥상의 단일 복도 구조를 게임에 적용했다. 현행 구현 범위와 한계는 [구현 기록](architecture-implementation-v1.md), 실제 화면은 [맵 적용 캡처](architecture-built-v1.html)를 확인한다. 아래 문서의 '이미지 검토 전용/실제 게임 미적용' 설명은 당시 상태 기록이다.

> v14 위생기구/창고 수정: 사용자가 방 위치 교환이 아닌 변기·샤워부스의 방향 반전을 선택했다. 1층 위생공간 칸 입구는 내부 통로 쪽으로, 등/설비는 외벽 쪽으로 정리한다. 관리실 뒤 창고는 문 안쪽 진입부를 비우고 선반을 왼쪽으로 모은다. [최신 단일 시안](access-renders-v11.html)과 [변경 기록](../Art/EnvironmentConcepts/v14-fixture-access/README.md)을 따른다.

> 1층 후속 수정 v13: 관리실 앞에 표현된 작은 방 두 칸을 없애고 [단일 통합 시안](access-renders-v11.html)으로 통일한다. 이전 별도 관리실 확대본과 1층 옆 수납방 추가안은 현행 기준에서 제외한다. 위쪽 객실 열과 관리실 뒤 창고는 유지한다. 2·3층 수납실 연결 및 3층 리모델링 방향은 유지한다. 1층 왼쪽의 좌표 평면은 후속 모델링 전에 이 시안과 정합화해야 한다.

> 출입 구조 후속 수정 v10: [출입문·관리실 기준](building-access-v10.md)과 [층별 평면](floor-plan.html)을 우선한다. 공용공간은 각자 주 복도 출입문을 갖고, 1층 관리실은 현재 게임의 작은 반벽·반유리/옆문 구조를 따른다. 상층 관리 수납실에서 옆 수납방으로 연결문을 추가한다. v8/v9 생성 조감도의 누락된 출입문과 다른 관리실 모양은 제작 기준이 아니다.

> 후속 수정 v9: 화재 피해를 본 **3층은 화재 후 리모델링한 깨끗한 층**으로 설정한다. 미색 벽지·회베이지 장판·교체된 타일/문틀을 사용하고 기존 좁은 구조와 307호 공실은 유지한다. 1·2층과 옥상의 노후 상태는 유지한다. 화재 흔적은 설비 뒤·보수 이음부·문틀 안쪽처럼 조사해야 보이는 위치에 제한하는 연출을 제안한다. [수정 시안 및 제작 기록](../Art/EnvironmentConcepts/v9-renovated-third-floor/README.md). 실제 게임 적용 전 이미지 검토 단계다.

2026-10-12. 최신 사용자 수정 기준. 현재 단계는 평면/콘셉트이며 실제 모델·NPC·게임 이벤트 구현 완료가 아니다.

> 후속 수정 v7: 사용자가 첨부한 2층 조감도를 공간·재질 기준으로 선택했다(`Art/EnvironmentConcepts/v7/user-selected-baseline.png`). 그 이미지에서 식탁 두 개만 원형으로 교체했고 모든 층 평면의 식탁도 원형으로 갱신했다. 1층과 2·3층의 샤워실 배분 차이는 유지한다. [문틈의 민서 사건](event-door-impostor.md)을 추가했다. 아직 실제 게임 적용은 아니다.

입주민의 문 앞 대화는 [걸쇠를 건 문틈 연출](resident-door-dialogue.md)을 기본으로 한다. 문은 살짝 열리지만 안은 어두워 얼굴이나 신체가 보이지 않고 진입은 막힌다. 입실 허락 시 문을 닫아 걸쇠를 푼 뒤 다시 연다. [공포 리듬 수정](horror-pacing.md)에 따라 갑툭튀는 주요 사건에 배치하고 추격은 본편 전체 1~2회를 초기 목표로 제한한다.

## 확정한 방향과 수정

- 모든 층의 휴게공간을 없앤다. 1층 기존 휴게실을 별도 샤워실로 전환한다.
- 2·3층 주방을 조금 줄이고 주방과 화장실 사이에 별도 샤워실을 넣는다. 상층 주방 너비는 v5 21.2m에서 17.2m로 약 19% 줄인 좌표 초안이며 깊이는 유지한다.
- 샤워실과 화장실은 각각 복도 출입문을 가진 독립 공간이다. 화장실에는 변기·세면대만 두고 샤워 헤드/칸은 전부 제거한다. 세면대 왼쪽/변기 칸 오른쪽 배치는 유지한다.
- 주방에는 각 층 식탁 2개를 둔다. 출입문 앞과 문 회전 공간을 비우고 조리대/냉장고는 반대편 벽에 둔다.
- 1·2·3층 오른쪽 계단 맞은편의 '복도 끝 구역'(x3110~3900, y-70~230)의 **복도 쪽 내부 경계벽만 철거**해 끝부분을 넓힌다. 외벽과 창, 옆 입주실 경계벽은 유지한다. 나머지 주 복도 1.30m, 방 크기와 출입문 간격을 바꾸지 않는다. 넓어진 끝부분에 새 휴게실이나 소파를 넣지 않는다.
- 사용자가 203호 공실 요청을 **202호로 정정**했다. 203호는 민서의 거주실을 유지한다. 202호·307호는 공실이며 매트리스 없는 침대 프레임과 책상 정도만 둔다. 다른 빈방은 완전히 비우거나 최소 가구/남겨진 흔적으로 차이를 준다.

## 입주민과 방 상태 초안

사용자 요청에 따라 층마다 약 5명, 총 약 15명 거주로 계획한다. 아래 신규 호수 배분은 제안이며 기존 민서/정숙/태오 등 거주 관계는 유지한다. 15명 모두를 매 순간 화면에 세우거나 15개 독립 장편 스토리로 만들지는 않는다. 주요 인물 외에는 귀가/수면/식사/샤워 상태, 문밖 짧은 대사, 생활음과 물건으로 재실감을 표현하고 공용 공간에서 일부를 만날 수 있게 한다.

| 층 | 거주 5실 | 조사 가능한 공실 3실 | 나머지 공실 4실 |
|---|---|---|---|
| 1층 | 101, 102, 104, 105, 107 | 103, 106, 109 | 108, 110, 111, 112 |
| 2층 | 203, 204, 206, 208, 211 | 201, 202, 209 | 205, 207, 210, 212 |
| 3층 | 301, 303, 305, 308, 311 | 302, 307, 310 | 304, 306, 309, 312 |

조사 가능한 방 9곳은 모두 동일한 공포방으로 만들지 않는다. 처음부터 열 수 있는 방과 관리 열쇠/사건 상태로 열리는 방을 구분하되 문밖 메모나 관리실 기록으로 잠긴 이유를 알 수 있게 한다. 내부를 조사한 뒤 다시 나올 수 있어야 하며, 모든 방 입장에 강제 잠금이나 추격을 붙이지 않는다. 거주실은 기본 노크·문밖 대화이며 입주민 허락이나 명확한 구조 상황에서만 입실시키는 방향이다. 나머지 공실도 영구 배경으로 확정하지 않고 사건 필요에 따라 접근 대상을 추가할 수 있다.

## 사건 공간을 넓히는 초안

| 공간 | 생활/조사 행동 | 사건 활용 제안 |
|---|---|---|
| 103·106·109호 | 퇴실 물품, 먼지 자국, 수리 흔적 조사 | 관리실 기록과 방 상태의 차이, 잘못 들은 생활음 |
| 201·202·209호 | 빈 프레임·책상·문 안쪽 잠금 흔적 | 202호 접근 여부 판단, 인접 방에서 소리의 실제 방향 비교 |
| 302·307·310호 | 그을음·보수 흔적·옛 문 번호 조사 | 307호 구조 요청과 비상통로에 대한 교차 증거 |
| 각 층 주방 | 식기·냉장고·입주민 식사 흔적 | NPC 마지막 목격 위치, 민원 시간/증언 비교 |
| 분리 샤워실 | 물소리·젖은 바닥·비어 있는 칸 조사 | 소리와 실제 사용 여부 불일치, 수건/발자국의 이동 방향. 노출된 인체 연출은 필요 없음 |
| 넓어진 복도 끝 | 창밖·계단 방향·남겨진 물건 확인 | 멀리서 짧은 목격, 시야가 트여 안심한 뒤 생기는 변화 |
| 계단·옥상 | 발소리 층수·빨래·점검 흔적 | 입주민 귀가 동선, 공격 없는 실루엣, 비상통로 접근 |

이 표는 이벤트 제작 후보이며 모든 칸에 별도 필수 퀘스트를 추가하는 약속이 아니다. 기존 사건 상태가 여러 조사 장소에서 드러나도록 연결한다. 시간·출입·NPC 위치로 결과가 달라지되 지나간 선택 목격을 못 봤다고 진행이 막히지 않게 대체 증거를 둔다. 추격은 전체 흐름에서 드물게 유지하고 귀신 목격/소리/조사는 추격과 분리한다.

## 구현 전 확인

- 각 샤워실은 독립 입구·탈의 자리·배수·사생활 칸막이·환기 배치를 이미지로 확인한다. 좁은 상층 샤워실의 유효 통로 폭은 실제 충돌로 검증한다.
- 욕실 내부에 샤워 시설이 남지 않았는지 모든 층을 확인한다.
- 개방한 복도 끝에 외벽 구멍이나 추락 지점이 생기지 않는다.
- 거주 5명은 실제 인구 설정이다. 방 개수/명단/CCTV/생활음/NPC 목격 상태가 모순되지 않게 같은 데이터를 쓴다.
- 민서가 203호 거주자로 유지되는지 통화·명단·대사·이벤트를 확인한다. 이번 단계에서는 런타임 스토리를 변경하지 않는다.
- 침대 프레임·책상만 둔 방도 조사 가능한 근거와 분위기를 가지며 모든 방을 동일하게 복사하지 않는다.

최신 평면과 생성 이미지는 `Art/EnvironmentConcepts/v6/`에 보관한다. 이전 문서에서 휴게실 유지·식탁 3개·화장실 내 샤워·203호 공실로 적힌 내용보다 이 문서를 우선한다.

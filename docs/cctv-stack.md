# 관리실 CCTV 구성

- 물리 모니터 5대: 아래 3대, 위 2대. 위쪽은 받침 선반으로 지지한다.
- 어느 모니터든 E로 화면을 열고, 각 화면의 좌우 버튼으로 8개 채널을 독립적으로 순환한다.
- 위 2개/아래 3개 순서는 확대 화면에서도 동일하다.
- 채널: 관리실, 1층 복도, 1층 주방, 2층 복도, 2층 주방, 3층 복도, 3층 주방, 옥상 계단.
- 모두 SceneCapture로 실제 공간을 촬영한다. 녹화는 최근 약 60초를 2fps로 유지한다.
- 되감기 중 채널을 바꾸면 같은 녹화 시각의 다른 카메라를 표시한다. 실시간 복귀 시 각 모니터의 채널 선택을 유지한다.
- 전원 차단과 사건에 의한 영상 정지는 기존 이야기 동작을 따른다.

현재 DAY 1 실행 맵에 기존 층 구조를 재사용한 3층과 옥상 진입 계단을 추가했다. 교대로 사용하는 두 계단 통로와 층별 연결참을 두어 위층 계단이 아래층 이동을 막지 않도록 했다. 옥상에는 출입 가능한 바닥과 외곽 난간이 있다. 이는 별도 승인 평면의 전체 재구축이나 옥상 빨래 연출까지 완성했다는 뜻은 아니다.

3층·옥상은 촬영 및 이동 가능한 기본 공간이며 전용 사건이나 추격 경로는 아직 제작하지 않았다. 기존 202호 입실·목격·노크 이벤트는 2층 높이에서만 발생하도록 범위를 제한했다. 307호는 빈 침대 프레임과 책상만 있는 공실로 둔다.

현재 모니터 부근에서 보이는 채널은 최대 5fps, 전체 채널 녹화는 2fps로 갱신한다. 실제 갱신 간격은 실행 성능의 영향을 받는다. 실시간 512×288, 녹화 256×144, 채널당 최대 120장으로 메모리를 제한한다. 녹화 이미지 자체는 최대 약 135MiB이며 렌더 타깃 관리 비용은 별도다.

기존 Meshy CRT를 복제하여 추가 생성 크레딧을 쓰지 않는다.

검증: `NRCCTVStackTest`에서 8개 채널의 실제 렌더링, 5대별 채널 순환, 녹화 시각 유지 및 실시간 복귀, 전원 차단, 2층→3층→옥상 실제 보행을 확인했다. `NRComplaintLogTest`, `NRExperienceTest`, `NROfficeCCTVTest`, `NRInvestigationTest`, `NRFeedbackTest`, `NRChoice202Test`도 실패 0으로 통과했다. 화면은 `docs/in-game-props-captures.html`에서 확인한다.

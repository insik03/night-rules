# 필수 문서 에셋 v1

2026-10-12. 기존 DAY 1 스토리 문구를 유지하며 게임 안의 문서를 실제로 읽을 수 있도록 제작.

## 이번 범위

1. **야간수칙**: 기존 관리실 규칙표에 명조체 7개 규칙을 적용. 2번 규칙 바로 아래에 ‘이 규칙은 거짓말입니다.’와 ‘아니야, 믿지 마!’가 나타난다. 기존 시간·시선·사건 조건을 유지한다.
2. **전임 총무 메모**: 책상 위 메모 표면에 손글씨로 전체 메모를 적용. E 열람도 같은 텍스처를 사용한다.
3. **전임 총무 장부**: 현관 기준 왼쪽 창고 선반의 실제 바인더에 ‘야간 업무일지 / 기록 담당: 도윤’ 표지를 적용. E를 누르면 기존 기록 전체를 확대 열람한다. 더 이상 장부 전체를 시간 제한 자막으로 보여주지 않는다.
4. **UV 점검등 안내**: 규칙표 왼쪽 벽에 조작과 카트리지 보관 장소를 안내하는 종이를 배치. E로 확대 가능. UV가 진실 판독기라는 설명이나 사건의 정답은 추가하지 않았다.

## 글씨체와 표현

- 본문·제목: Nanum Myeongjo Regular / Bold.
- 붉은 글씨와 메모: Nanum Brush Script. 붉은 두 문구는 동일한 글꼴, 크기, 색, 등장 처리 사용. 필체로 작성자를 구분할 수 없도록 유지.
- 미색 종이와 약한 가장자리 변색. 가독성을 해치는 핏자국·과한 얼룩 없음.
- 원본 문구: `NightRulesPrototype/Content/Data/day1.json`. 새 UV 조작 안내도 같은 파일에서 관리.
- AI 생성 이미지/새 Meshy 작업 없음. 기존 소품 표면과 기본 종이판 사용. 추가 크레딧 0.

## 게임 연동

- 벽의 규칙표와 확대 열람은 같은 원본과 같은 붉은 글씨 진행 값을 사용한다.
- 작은 메모·표지는 기존 상호작용을 가리지 않는 별도 종이 표면으로 부착한다.
- E로 열기, 마우스 휠 스크롤, Esc 닫기. 문서 화면을 닫거나 CCTV/민원 장부로 바꾸면 이전 종이가 남지 않도록 분리.
- 읽은 내용의 증거 기록과 기존 보고 조건 유지. 대화 전용 더빙 원칙 유지.
- Fonts 폴더의 원본 글꼴과 저작권/OFL 문서를 배포본에 포함. 출처·해시는 `Content/Fonts/SOURCES.md`와 `Art/StoryProps/provenance.json`에 기록.

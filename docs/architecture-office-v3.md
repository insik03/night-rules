# 1층 관리실·창고 통합 / 현관 양문

2026-10-12. 최신 사용자 요청에 따른 변경. v2의 1층 관리실 배치를 대체한다.

## 확정 내용

- 건물 입구: 두 짝짜리 양문. 90cm 문짝 두 개, 190cm 벽 개구부. 양쪽 손잡이는 중앙, 문은 바깥으로 열림. 어느 문짝과 상호작용해도 함께 개폐되며 기존 근무 중 잠금 유지.
- 기존 창고 전체: X=-500..430, Y=-900..-480 cm. 폭 930 × 깊이 420 cm.
- 새 관리실: X=-500..-35. 새 창고: X=-35..430. 벽 중심선 기준 각각 폭 465 × 깊이 420 cm. 중앙 12cm 벽으로 분리.
- 관리실 문: (-105,-480), 창고 문: (197.5,-480). 현관 홀에서 각각 직접 들어가며 87cm 개구부 앞뒤 동선을 비움.
- 관리실 창: 전면 X=-500..-170 / Y=-480. 아래 130cm 벽, 위 유리. 책상과 CCTV는 창 안쪽, 출입문은 오른쪽에 별도 배치.
- 기존 관리실 X=-500..-220 / Y=-480..-200의 전면벽·옆벽·옆문을 제거해 현관 홀로 통합.
- 청소 선반·UV 카트리지·공구함·전임 총무 장부는 오른쪽 창고에 배치.
- 2·3층 및 주방·화장실·샤워실·계단은 변경하지 않음. 신규 Meshy 생성 없음, 추가 크레딧 0.

## 게임 연동

시작/각성/체크포인트 위치, 전화와 환경음, CCTV 카메라, 장부, 서랍, 규칙표·붉은 글씨, 복귀 사건은 새 관리실 기준으로 맞춤. `NRLayout::InOffice`로 공간 판정을 통일하여 이전 관리실이나 창고에서 관리실 전용 사건이 발생하지 않도록 함. 규칙표와 벽시계는 새 뒤 벽에 부착.

## 시각 자료

`architecture-office-v3.html`에 설명도와 실제 실행파일 촬영본을 함께 둠. 조감도는 도면 방향에 맞춰 좌우 반전 표시하고 확인용 조명 사용. 플레이 화면은 반전·색 보정 없음. 전체와 확대는 동일한 게임 모델. 기존 소품을 재사용한 구조 검토용 프로토타입이며 최종 아트가 아님.

## 현관 시야 확인 · 2026-10-12

사용자가 창 옆 벽과 관리실 좌우 배치를 지적하여 현재 실행파일을 정면에서 다시 촬영했다. 기존 근접 사진은 좌측으로 25도 돌아 관리실만 담아 오른쪽 창고를 보여주지 못했다. 새 촬영은 현관 안 (-35,155,90)에서 yaw=-90, 기본 FOV 85이며 좌우 반전이나 조명 변경을 하지 않았다. 좌측 외벽 X=-500에 붙은 관리실과 우측 창고가 함께 보인다. 지도 구조나 벽 위치 변경은 하지 않았으며, 안내 페이지의 첫 실제 화면을 정면 사진으로 교체했다. 관리실 안에서 현관을 보는 반대 시야도 추가했다. 촬영본: Art/Previews/Architecture-v4/.

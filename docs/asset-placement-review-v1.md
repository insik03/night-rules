# 에셋 좌표·배치 검토 — 2026-11-05

단위는 모두 **cm**, 회전은 UE 월드 Z축 yaw(도)다. 런타임 변경은 세면대·변기 뒤쪽 밀착만이다. 그 밖의 14종은 **제작·배치 제안**이며 게임에 추가하지 않았다. 커밋, 유료 3D 생성, 엔진 빌드·패키징·게임 테스트는 실행하지 않았다.

## 1. 현재 메시와 교체 컨셉을 구분한 위치 보정

기존 FBX를 별도 Blender background 프로세스에서 읽기 전용으로 측정했다. UAsset의 Asset Registry ApproxSize 문자열도 각각 150x55x112 / 44x62x83 / 240x68x89로 일치한다. UAsset의 정확한 런타임 bounds를 엔진에서 측정한 결과는 아니다. 코드는 로드된 메시를 회전시킨 후 `CalcBounds(ComponentTransform)`의 Min을 사용하므로 피벗 비대칭이나 교체 메시 치수에 종속되지 않는다. 원본 메시·스케일은 변경하지 않았다.

- 세면대: 칸막이 안쪽 `X=ToiletL+6`, 현행 회전 후 뒤쪽 오프셋 -27.5이므로 피벗은 `ToiletL+33.5`. 사용자 예시 `ToiletL+36`은 깊이60cm 중앙 피벗의 새 컨셉일 때 맞는다.
- 변기: 현행 로컬 Y는 -29.5~33으로 비대칭이다. 뒷벽 안쪽 -892에서 뒤쪽 오프셋 -29.5를 빼면 피벗 **-862.5**. 새 깊이70cm 중앙 피벗일 때는 **-857**.
- 변기 X: 1층 2000 / 2220 / 2440, 2·3층 2904.1667 / 3142.5 / 3380.8333. Z는 각 층 바닥 0 / 320 / 640 유지.
- 현재 메시 계산상 변기 전면은 Y=-829.5. 칸막이 시작선 -620까지 **209.5** 남으며, 칸막이·외벽과 좌우 최소 간격은 1층 **82**, 2·3층 **91.1667**. 뒷벽 틈은 0.
- 세면대 전면부터 첫 변기 칸막이 안쪽까지 **145**. 세면대 폭150은 Y방향으로 놓이고 Y=-695~-545를 차지한다.
- 플레이어 캡슐은 지름56. 위 값은 정적 기하 계산이며 실제 이동·메시 collision hull·상호작용을 통과했다는 뜻이 아니다.
- 세면대 위 열쇠표는 기존 NRDemo.cpp의 실제 상판 trace 배치가 유지된다. 위치 보정 후 자동 플레이의 열쇠표 조사도 Claude가 재확인해야 한다.
- layout의 width/depth/height는 기존 교체 컨셉 목표를 유지하고, `runtime_dimensions_cm`, `runtime_mesh`, `concept_wall_aligned_xy_cm`으로 현재 메시와 구분했다.

## 2. 식기 건조대 A/B — 사용자 선택 필요

공용주방 현행 코드에 싱크대가 없다. 아래 두 안은 서로 배타적이며 모두 제안이다. 1층 주방 문 중심은 (1055,-200), 2·3층은 (1302.5,-200); 바닥은 0/320/640.

| 안 | 1층 좌표 | 2·3층 좌표 | 장점 / 조건 |
|---|---|---|---|
| A: 싱크대·하부장 먼저 제작 | 싱크대 (705,-840), 120×60×85. 건조대 (740,-840), 바닥에서85 | 싱크대 (1155,-840). 건조대 (1190,-840), 바닥에서85 | 세척·건조 위치가 자연스럽다. 오른쪽45cm 배수판과 왼쪽 싱크볼이 있는 상판 설계가 선행되어야 한다. |
| B: 기존 조리대 위 | 건조대 (990,-840), 바닥에서89 | 건조대 (1440,-840), 바닥에서89 | 추가 하부장 없이 가능. 다만 싱크·급배수 기능은 생기지 않는다. |

건조대는45×30×18, yaw0, 새 싱크대도 yaw0(+Y 방향을 앞면으로 제작하는 조건). A안은 기존 도면의 싱크대 제안 위치를 이용한다.

- A 싱크대와 조리대의 X방향 간격15. 싱크대 북쪽 앞면 Y=-810과 가까운 식탁 의자 남쪽 끝 -707 사이 **103**. 뒤쪽 Y=-870과 뒷벽 안쪽 -892 사이22는 현재 제안의 배관 여유다. 실제 배관 마감은 미정.
- B는 바닥 점유가 늘지 않는다. 현행 조리대 앞면 Y=-807.5와 의자 남쪽 끝 -707 사이 **100.5**. 문은 Y=-200 부근이므로 양안 모두 문 회전 영역에서 벗어난다.
- 1층 데모 경로 (1055,-750)→(950,-750)에서 조리대까지57.5, 플레이어 반경28을 빼면 **29.5**의 정적 여유. A 싱크대는 더 서쪽에 있어 이 구간에 걸리지 않는다.
- 하부장 여닫이문 개방 폭은 미정이다. 예를 들어60cm 문을 북쪽으로 열면 의자까지43cm만 남아 지름56 캡슐의 통로로 쓰기 어렵다. A 선택 시 미닫이 또는 작은 분할문 등 개폐 설계를 별도로 검토해야 한다.
- 밥솥과 건조대는 1층 중앙 예비 퓨즈 (900,-840)를 덮지 않는 쪽으로 분리했다. 상부장의 실제 설치 높이도 제작 시 확인해야 한다.
- 생활 공간 완성도 측면에서는 A를 권장하지만, 선택 전 신규 싱크대나 소품을 런타임에 추가하지 않는다.

## 4. 파일 정리·검증 범위

- `docs/remaining-assets-images-v2.html`을 유일한 검토 페이지로 유지.
- 내용과 SHA256이 같던 `docs/remaining-assets-images-v1.html` 삭제.

# 추격 소리와 의자 사망 연출

2026-10-18. 기존 승인 귀신과 202호 의자 모델을 재사용한다. Meshy/Tripo 신규 생성 비용은 없다.

## 플레이 의도

202호에서 들리는 의자 소리는 뒤에 나타나는 귀신이 의자를 끄는 행동의 복선이다. 추격을 추가로 발생시키지 않고 기존 DAY 1 및 최종밤의 붙잡힘 결과에 연결한다. 의자를 실제로 끌고 이동하는 동안만 위치 기반 마찰음이 난다. 멈춤·문서 화면·추격 종료에서는 마찰음이 멎는다.

플레이어의 발소리는 밑창과 뒤꿈치가 구분되는 5종, 귀신은 더 낮고 무거운 5종을 사용한다. 연속 중복을 피하고 피치를 소폭 변화시킨다. 웅크리기는 작게, 달리기는 크게 들린다. 귀신의 발소리 간격은 이동 속도와 달리기 애니메이션에 맞춘다.

## 붙잡힘

| 경과 | 동작 / 소리 |
|---|---|
| 0–0.55초 | 조작이 멎고 시선이 낮아진다. 한 손은 뒤쪽 의자에 붙어 있다. |
| 0.55–1.5초 | 의자를 들어 올리며 끌리는 소리가 멎는다. |
| 1.5–1.72초 | 머리 위에서 짧게 멈춘다. |
| 1.72–1.94초 | 시점 앞으로 의자를 내려친다. |
| 1.94초 | 타격음과 동시에 암전. |
| 2.8초 | 사망 문구와 재시작 안내. |

타격 자체의 신체 훼손을 보여주지 않는다. 재시작은 카메라 높이·암전·의자·음원을 복구한다. 낙하 등 귀신 접촉 이외 사망에는 이 연출을 사용하지 않는다.

## 재현과 검증

- `tools/design_footsteps.py`: CC0 소스에서 발소리 10종과 의자 타격음 제작.
- `tools/create_chair_execution.py`: 기존 귀신 리그에 오른손 IK를 구워 추격/사망 클립 생성.
- `tools/import_footsteps.py`, `tools/build.ps1 -ImportFootsteps -Package`: 전용 임포트와 빌드.
- `-NRPursuitTest`: 쿠킹된 음원·리그·의자 로딩, 비반복 샘플 선택, 붙잡힘/타격/재시작 순서 검증 및 게임 믹스 녹음.
- 영상의 긴장음은 쇼케이스용 후편집이다. 게임에 반영하는 범위는 발소리, 의자 이동음과 사망 연출이다.

기존 DAY 2–4 미구현 범위는 이 작업으로 완성되지 않는다.

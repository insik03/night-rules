# 입주민 대화 — 안전 걸쇠를 건 문틈 연출

2026-10-12 사용자 요청. 향후 구현 기준이며 현재 게임에 반영된 기능이 아니다. 문/걸쇠/NPC 이미지를 먼저 보여준 뒤 모델링한다.

사용자 추가 요청으로 [문틈 대화 상대가 귀신인 사건](event-door-impostor.md)을 설계했다. 실제 주민의 재실과 사칭 존재의 응답을 분리하며, 정상 대화를 충분히 경험한 뒤 드문 사건으로 사용한다. 기본 대화에 무조건 추격/사망을 붙이지 않는다.

## 기본 흐름

노크 → 방 안의 반응/발소리 → 기본 잠금을 푸는 소리 → 문이 안쪽으로 조금 열림 → 걸쇠가 팽팽해지며 문이 멈춤 → 문틈 너머 입주민과 대화 → 문을 닫고 잠금.

- 안전 체인 또는 걸쇠를 **걸어 둔 상태**에서 문이 제한된 각도만 열린다. 초기 틈 8~12cm/약 8~12도는 문 너비에 따른 조정값이다. 장치 형태를 이미지로 확정하기 전 수치/모델을 고정하지 않는다.
- **문틈 안은 어두워 얼굴·눈·입·손 등 상대의 신체를 식별할 수 없게 한다.** 이전의 얼굴 일부 노출안은 철회한다. 정상 주민과 사칭 존재 모두 같은 방식으로 가려 '얼굴이 안 보이면 귀신'이라는 공식이 생기지 않게 한다. 복도 빛에 문 가장자리·문틀·안전 걸쇠는 읽혀야 한다.
- 주민은 문짝 뒤나 문틀에 가려진 위치에서 응답한다. 손전등은 문/걸쇠에 정상 반응하고 임의로 꺼지지 않는다. 얼굴을 문틈 정면에 두고 검은 화면으로 덮는 대신 차폐·배치·실내 조명으로 가린다. UV도 얼굴/작성자의 진위를 판정하는 도구가 되지 않는다.
- 문틈만 열리면 실내 조명과 목소리의 차폐 정도가 함께 변한다. 자막은 기존 겹침 방지 규칙을 유지하고 한국어 음성은 실제 대사에만 붙인다.
- 플레이어의 시선을 강제로 고정하거나 갑자기 확대하지 않는다. 걸쇠 때문에 밀고 들어갈 수 없고, 몸/카메라가 문 또는 주민을 관통하지 않아야 한다.
- 입주 허락 시 문을 먼저 닫아 걸쇠를 풀고 다시 완전히 연다. 걸린 체인을 그대로 늘리며 통과시키지 않는다.
- 공실은 기본적으로 주민의 답이 없다. 공실에서 반응이 있는 경우 명시적인 사건 상태로만 발생한다. 입주민이 주방/샤워실/외출 중이면 문 안에서 동시에 응답하지 않는다.
- 전화 통화와 공용공간 대화는 기존 방식이며 문틈 연출을 억지로 적용하지 않는다.

## 구현 상태안

`ClosedLocked → Knocked → Answering → ChainedAjar → Talking → Closing → ClosedLocked`

초대받는 경우 `Talking → Closing → Unchaining → OpenInvited`. 대화 중 재노크/문 연타로 음성이나 문 동작이 중첩되지 않게 한다. 걸쇠는 시각 장식만이 아니라 제한 각도와 충돌 상태에 연결한다. 서 있는 주민과 재실 상태/문/음성을 같은 사건 상태에서 갱신한다.

이 연출은 층당 약 5명 거주 설정과 연결한다. 공용공간에서 만나는 NPC 외형·목소리·가동부 자산은 별도 이미지 확인 대상으로 유지한다. 문틈 대화 예외(긴급 구조, 이미 열린 문, 복도에서 직접 만남)는 사건 이유가 있을 때만 사용한다. [최신 공포 리듬](horror-pacing.md)에 따라 갑툭튀는 선정된 사건에서 사용하되 평범한 대화마다 반복하지 않는다.

# 승인 시안과 구현 불일치 수정

기준 이미지: `Art/EnvironmentConcepts/v14-fixture-access/floor1-master.png`.
추가 Meshy 생성/크레딧 사용 없음. 기존 4개 생성 모델을 재사용한다.

## 이전 적용의 문제

- v1은 이미지와 다른 옛 공용공간 좌표를 그대로 사용했다. 특히 1층 주방 폭이 895cm여서 이미지의 공간 배분과 달랐다.
- 280cm 너비의 관리실이 서쪽 외벽에서 360cm 떨어져 있었다.
- 이미지의 미색 벽과 무채색 몰딩 대신 꽃무늬가 있는 Meshy 표면을 반복 사용했다.
- 조감도에 층별 기존 조명이 남았고 1층에만 밤하늘 구체가 남아 검토 조명을 가렸다. 같은 마감인 1·2층을 같은 조건으로 비교하지 못했다.
- 게임 이동 검사 통과를 승인 이미지와의 시각적 일치로 잘못 확장해 설명했다.

## 수정

- 관리실의 크기·반벽/반유리·옆문은 유지하고 전체를 서쪽 외벽에 붙인다. 관리실 책상과 소품, 첫 시작·각성 위치, CCTV, 이동 검사도 함께 이동한다.
- 1층 주방을 x430~1680(1250cm), 화장실 x1680~2550, 샤워실 x2550~3500으로 재배분한다. 각 입구는 해당 공간 중앙으로 이동하며 두 원형 식탁의 간격도 조정한다.
- 1·2층은 동일한 미색 벽과 탁한 청록 장판을 사용한다. 기존 꽃무늬를 제거하고 월드 좌표 기준 재질로 크기를 통일한다. 3층은 별도의 깨끗한 마감을 유지한다.
- 비교 조감도에서는 밤하늘 구체를 제외하고 모든 기존 조명을 끈 뒤 동일한 검토 조명·고정 노출을 적용한다. 일반 게임 조명은 별도이며 기존 70% 광량 정책을 유지한다.
- 비교 페이지에서 조감도만 도면 좌우 방향에 맞춰 반전 표시한다고 명시한다. 원본 PNG 링크도 제공하며 플레이 캡처는 반전하지 않는다.

이 버전은 구조·재질의 불일치 수정이다. 시안의 모든 소품과 디테일을 복원한 최종 미술 버전으로 부르지 않는다. 작은 소품과 외부 비상계단 연속 보행은 이번 범위가 아니다.

비교 화면: [시안 대조](architecture-reconcile-v2.html).

# 4주 검증 계획

**목적:** 고시원(야간수칙) vs 심야 전당포 중 어디에 남은 5개월을 넣을지 결정한다.

**원칙:** 이 4주에 만드는 것은 전부 **버릴 물건**이다. 재사용하려고 예쁘게 만들지 않는다.

| 주차 | 작업 |
|---|---|
| 1주 | 클립 아이디어 10개씩 + 고시원 프로토타입 |
| 2주 | 전당포 프로토타입 |
| 3~4주 | 클립 3개씩 제작 → 업로드 → 반응 관측 |
| 4주 끝 | **확정** |

---

# PART 1 — 1주 프로토타입

공개하지 않는다. 못생겨도 된다. 텍스처 0장, 모델링 0개가 목표다.

예산: 5일 × 5시간 = **25시간**. 초과하면 그 자체가 신호다.

---

## 1-A. 고시원 프로토타입

### 검증 질문

> **붉은 글씨를 본 뒤, 시키지 않아도 규칙표 앞으로 돌아가는가?**

이거 하나만 본다.

### 만들 것

- [ ] 1인칭 이동 + 상호작용 1개 키(E)
- [ ] 관리실 1개 — 책상, 전화기, 벽에 규칙표
- [ ] 복도 1개 — 방문 4개, 그중 203호만 열림
- [ ] 규칙표 — UI 캔버스, 규칙 5줄. 텍스트로 충분
- [ ] 전화 — 벨 울림 → E → 텍스트 대사 1건 "203호에서 자꾸 소리가 나요"
- [ ] 사건 상태 3단계
  - State 1: 민원 접수
  - State 2: 3분 경과 — 203호에 아무도 없음 + 노크 소리
  - State 3: 7분 경과 — 두 번째 전화
- [ ] 관리실 복귀 시 규칙표에 **붉은 글씨 1줄 추가**되어 있음
- [ ] 사운드 3개 — 전화벨, 노크, 발소리

### 안 만들 것 (어기면 1주가 3주 된다)

- ❌ 텍스처, 머티리얼 — 회색 큐브 그대로
- ❌ 조명 세팅 — 기본 조명 그대로
- ❌ NPC 모델, 애니메이션
- ❌ CCTV
- ❌ 입주자 명단 PC
- ❌ 2층 이상
- ❌ 사건 2개 이상
- ❌ 세이브
- ❌ 타이틀/메뉴 화면
- ❌ 사운드 4개 이상
- ❌ 음성

### 일별

| Day | 작업 |
|---|---|
| 1 | 이동 + 상호작용 + E키 시스템 |
| 2 | 관리실/복도 그레이박스 |
| 3 | 규칙표 UI + 전화 |
| 4 | 사건 상태 3단계 + 붉은 글씨 등장 |
| 5 | 사운드 3개 + 플레이 |

### 판정

본인이 3번 돌려본 뒤, **다른 사람 2~3명**에게 아무 설명 없이 시킨다.

- 붉은 글씨를 본 뒤 규칙표로 **자발적으로** 돌아가면 → 통과
- "그래서 뭐 해야 되는데?"가 나오면 → §3 HUD 최소화 원칙에 문제가 있는 것
- 돌아가지 않고 그냥 203호만 계속 보면 → 규칙이 게임의 중심이 아닌 것. **컨셉의 핵심이 작동하지 않는다는 뜻**

## 1-B. 전당포 프로토타입

### 검증 질문

> **값을 부를 때 망설이는 순간이 있는가?**
>
> **3일차가 끝났을 때 4일차가 궁금한가?**

망설임이 없으면 이 게임은 존재하지 않는 것이다. 감정 경영의 재미는 전부 그 3초에 있다.

### 만들 것

- [ ] 카운터 화면 1개 — 책상, 손님이 서는 자리
- [ ] 손님 — **모델 없음.** 실루엣 또는 2D 초상화 + 이름 + 대사 텍스트
- [ ] 물건 10종 — 프리미티브 도형 + 이름/설명 텍스트. 각각 내부적으로 `진짜 가치` 보유
- [ ] 감정 — 지표 3개(무게 / 각인 / 상태)를 각각 따로 확인. **표시값에 노이즈를 섞는다**
  - 지표를 다 확인해도 진짜 가치를 정확히는 알 수 없어야 한다
- [ ] 가격 부르기 — 숫자 입력 또는 슬라이더
- [ ] 손님 반응 — 수락/거절. 임계값 로직 한 줄이면 충분
- [ ] 하루 정산 — 매입 총액 / 현금 잔액 / 다음 날 임대료
- [ ] 저주 물건 1개 — 매입하면 다음 날 아침에 사건 발생. **텍스트 한 줄로 표시해도 됨**
- [ ] 3일치 플레이

### 안 만들 것

- ❌ 진열/판매 시스템 — **매입만.** 파는 건 다음 단계
- ❌ 평판 시스템
- ❌ 손님 종류 3개 초과
- ❌ 3D 모델링, 텍스처
- ❌ 애니메이션
- ❌ 밸런싱 — 숫자는 대충 넣는다. 지금 튜닝하면 5일이 사라진다
- ❌ 세이브
- ❌ 메뉴 화면
- ❌ 사운드 (정산음 1개면 족함)

### 일별

| Day | 작업 |
|---|---|
| 1 | 물건 데이터 구조 + 카운터 화면 |
| 2 | 감정 지표 3개 + 노이즈 |
| 3 | 가격 부르기 + 손님 수락/거절 |
| 4 | 하루 정산 + 3일 루프 |
| 5 | 저주 물건 1개 + 플레이 |

### 판정

- 값을 부를 때 **망설였다** → 통과
- 계산기처럼 정답이 딱 나온다 → 노이즈가 부족하거나, 지표가 너무 정직하다. 조정 후 재판정
- 3일차 끝에 4일차가 안 궁금하다 → 경영 루프가 성립하지 않는 것. **이 컨셉은 여기서 접는다**

## 2-A. 고시원 클립 3개

### 클립 ①「규칙」 — 15초

```

      카메라가 천천히 아래로 내려간다.
0:06  4번째 줄 옆 여백에
```

```
0:00  어두운 복도. 노크 소리.

      「3. 노크 소리가 나면 문을 열지 마십시오.」
```

# PART 3 — 측정과 판정

## 업로드

- TikTok / YouTube Shorts / Instagram Reels — 동일 클립 전부 업로드
- Reddit — r/IndieGaming, r/horrorgames, r/IndieDev
- 컨셉당 3개, 2주간 관측

### 계정

- **게임 개발용 계정 하나를 새로 만든다.** 개인 계정 사용 금지
- 스튜디오명으로 운영한다. 실명·얼굴 노출 필요 없음
- **두 컨셉을 같은 계정에 올린다.** 계정을 나누면 팔로워 수·계정 신뢰도가 달라져서 A/B 비교가 오염된다
- 프레이밍: "두 개를 만들고 있는데 어느 쪽이 나아 보이나요" — 미완성 그레이박스를 올리는 건 devlog 문화상 정상이다. 오히려 반응을 유도한다
- TikTok / Reels / Shorts는 **팔로워 0이어도 노출된다.** 이게 이 테스트가 성립하는 이유다
- Reddit은 다르다. 계정 나이와 카르마, 서브레딧별 자기홍보 규칙이 있다. **지금 계정을 만들어 2주간 방치**해두면 3주차에 쓸 수 있다

### 자막 언어

- 자막은 **영어**
- 단, 화면 안 오브젝트(규칙표, 장부, 메모)의 글자는 **한국어 그대로 둔다**
- 해외 시청자에게 이국적 요소로 작동한다. 번역하면 분위기가 사라진다

### 업로드 리듬

- 3개를 한 번에 올리지 않는다. **2~3일 간격**으로 하나씩
- 알고리즘이 각 클립을 개별적으로 테스트하게 둔다
- 컨셉을 번갈아 올린다: 고시원① → 전당포① → 고시원② → 전당포② …
- 해시태그·업로드 시간 같은 잔기술은 신경 쓰지 않는다. **첫 1초가 그 전부보다 중요하다**

### 각오할 것

- 3개 중 2개는 조회수가 거의 안 나온다. **정상이다**
- 1개만 반응이 오면 그것으로 데이터는 충분하다
- 조회수 0이 나와도 그건 컨셉에 대한 판정이 아니라 **그 클립에 대한 판정**이다

## 볼 지표

조회수는 **후순위**다. 알고리즘 편차가 크다.

| 우선순위 | 지표 | 의미 |
|---|---|---|
| 1 | **저장 / 공유 수** | 다시 보고 싶다는 뜻 |
| 2 | **"언제 나와요" 계열 댓글 비율** | 구매 의사에 가장 가까운 신호 |
| 3 | 댓글에서 컨셉을 **정확히 이해했는지** | 후크가 설명 없이 작동하는지 |
| 4 | 조회수 | 참고만 |

## 판정선

| 결과 | 결정 |
|---|---|
| 한쪽 지표 합계가 **3배 이상** | 그쪽으로 확정 |
| 3배 미만 차이 | **프로토타입 재미**로 결정 (PART 1 판정 결과) |
| 양쪽 다 조회수 1,000 미만 | 컨셉이 아니라 **클립 제작**의 문제일 수 있다. 1회만 재촬영. 두 번은 하지 않는다 |

## 4주가 끝나면

**결정을 미루지 않는다.**

애매하면 PART 1의 프로토타입 판정을 따르고, 그것도 애매하면 **본인이 클립 아이디어 10개를 더 잘 뽑아낸 쪽**으로 간다.

6개월을 붙어 있어야 하는 건 결국 아이디어가 계속 나오는 쪽이다.

# 부록 — 지금 바로 하는 공짜 테스트

프로토타입을 시작하기 전에, 앉은 자리에서 한 번에:

**각 컨셉으로 클립 아이디어를 10개씩 적는다.**

| 결과 | 해석 |
|---|---|
| 고시원 10개가 술술 나온다 | 예상됨. 붉은 글씨는 아이디어 생성기다 |
| 전당포에서 5개쯤 막힌다 | 전당포는 수익 기대치가 높아도 **당신에게는 틀린 선택**이다 |
| 양쪽 다 술술 나온다 | 좋은 신호. PART 1~3을 계획대로 진행 |
| 양쪽 다 막힌다 | 두 컨셉 다 아니다. 4주 쓰기 전에 알게 된 게 이득이다 |

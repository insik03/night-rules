# 관리실 CCTV의 실제 사용자 위치 확인 (2026-10-10)

사용자가 캐릭터가 여전히 안 보인다고 보고했다. 이전 구현은 이미지 생성으로 만든 인물이 아니라 엔진 기본 도형 15개를 조합한 임시 몸체다. 이 부분은 그대로이며, 완성된 인물 모델은 아직 없다.

확인된 배치 문제: 두 카메라가 복도를 향했기 때문에 관리실 책상에서 실시간 화면을 읽는 플레이어 자신은 촬영 범위에 없었다. 이전 테스트는 플레이어를 2층 복도로 이동시켜 몸체를 확인했으므로 실제 CCTV 사용 위치를 검증하지 못했다. 사용자에게서 정확한 재현 화면에 대한 답을 받기 전이므로, 되감기 또는 1인칭 몸체에 관한 모든 보고까지 해결됐다고 간주하지 않는다.

## 변경

- CAM 01을 관리실 상단 모서리로 옮겨 책상 앞과 옆문을 촬영한다. UI 이름도 ‘관리실 / 옆문’으로 변경한다. 기존 1층 출입 복도 방향을 대체한다.
- CAM 02의 202/203호 복도 촬영은 유지한다.
- 물리적인 책상 모니터도 CAM 01을 보여 준다. 되감기와 실시간 복귀도 같은 채널을 유지한다.
- 이번 작업에서 인물 이미지나 새로운 3D 캐릭터 에셋을 생성하지 않았다. 임시 몸체는 1인칭 화면에는 보이지 않고 CCTV 캡처에만 표시된다.

## 검증

`NROfficeCCTVTest`는 플레이어를 촬영 위치로 옮기지 않는다. 실제 시작 위치에서 모니터 표면을 조준하고 `Player->Interact()`로 화면을 열며, 몸체가 있을 때와 없을 때의 CAM 01 픽셀을 비교한다. 책상 모니터의 채널도 함께 확인한다. 테스트 동안 마우스 시점 입력만 막아 사용자 커서 움직임이 캡처 방향에 영향을 주지 않게 했다.

에디터 게임 모드에서 다섯 항목 통과. Windows 패키지에서도 같은 검사를 수행하고 스크린샷을 `Art/Previews/cctv-office-player.png`에 보관한다. 기존 녹화/되감기는 `NRExperienceTest`, 2층 몸체/UV/규칙은 `NRInvestigationTest`로 확인한다.

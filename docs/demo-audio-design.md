# 데모 사운드 v1

`tools/create_demo_audio.py`가 외부 녹음·음성·생성 서비스 없이 결정적 파형 합성으로 만든 12개 WAV. 44.1kHz, mono, signed 16-bit. 길이·peak·RMS·루프 여부는 `Art/DemoAudio/manifest.json`에 기록한다. 합성 초안이며 최종 녹음 소스의 질감과 같다고 주장하지 않는다.

| 파일 | 역할 | 루프 |
|---|---|---|
| fluorescent_hum | 형광등 100/200Hz 저음 | 예 |
| room_tone | 주방 모터/공용공간 저주파 | 예 |
| power_trip | 퓨즈 단선과 조명 소등 | 아니오 |
| power_return | 재점등 릴레이 | 아니오 |
| chair_drag | 202호 의자 마찰 | 아니오 |
| pipe_knock | 배관/벽 너머 노크 | 아니오 |
| door_slam | 관리실 문 닫힘 | 아니오 |
| distant_steps | 천장/복도에서 멀어지는 발소리 | 아니오 |
| breath_near | 어깨 뒤 비언어적 숨소리 | 아니오 |
| radio_static | CCTV 전원 잡음 | 아니오 |
| metal_rattle | 열쇠와 점검구 진동 | 아니오 |
| chase_pulse | 선택적 추격 레이어, 현재 미사용 | 예 |

4개 환경음 위치: 관리실, 2층 복도, 1층 주방, 1층 공용공간. 80cm 내경/1250cm 거리 감쇠와 월드 가림 검사·1100Hz 저역 필터. 정전 시 환경음도 감소한다. 랜덤 놀래키기 대신 위치/사건에 연결된 일회성 소리를 우선하며 간헐적 소리는 낮은 볼륨으로 재생한다.

추격 중에는 기존 `step` 효과음을 귀신의 실제 발 위치에서 약 0.83초 간격으로 재생한다. 이동할 때만 발생하며 거리와 벽 가림을 반영한다. 두 번째 추격 시작 지점에서 고정 재생하던 8초 발소리는 제거해, 실제 이동 방향과 소리 방향이 어긋나지 않게 했다. 음량과 공포 체감은 청감 플레이테스트가 필요하다.

마지막 307호 통화는 3초 시점에 전화기, 6초 시점에 관리실 문밖에서 기존 3회 노크 효과음을 재생한다. 통화를 진행하는 동안만 시계가 흐르고, 일시정지나 기록 확대 화면에서는 멈춘다. 관련 문구도 관리실 문밖으로 맞췄다. 종료를 늦추기 위한 대기 시간은 추가하지 않는다.

Claude Code 요청은 조직 정책 API 403으로 거절되었다. 실제 작성자는 Codex이며 Claude 공동 작업으로 표시하지 않는다.

# DAY 1 구현 기록

## 승인 범위

사용자가 승인한 `story-draft.md` v0.2의 DAY 1을 먼저 구현한다. 고시원 이름은 해담고시원.
본편과 Steam 공개 데모는 향후 완성 단계이며 현재는 비공개 첫 구현이다.

## 구조

- `ANRGameMode`: 시작 시 공간 생성, 사건 시간, 전화·단서·붉은 글씨 상태, 체크포인트, 행동 로그.
- `ANRPlayer`: 1인칭 카메라, 이동, 상호작용 레이, 일반/UV 손전등, 카트리지와 발소리.
- `ANRProp`: 문·전화·문서·카트리지. 생성된 FBX가 있으면 전화기·의자·카트리지에 적용한다.
- `day1.json`: 한국어 대사·문서와 시간/소모량. 전임 총무의 흔적은 현장 판단에 쓰이고 작성자를 알려주지 않는다.
- CCTV: 각 층 SceneCapture2D → RenderTarget → Slate 조사 화면. 현재 영상과 저장 기록을 구분한다. 영상 확인 중에만 약 5fps로 캡처한다.
- Slate UI: 장비 잔량, 가까운 상호작용 안내, 읽는 문서. 퀘스트 목록이나 신뢰도 점수 없음.
- 체크포인트: 202호 문을 열기 직전 플레이 상태의 메모리 스냅샷. 디스크 SaveGame은 후속 단계.

## 첫 구현의 단순화

방문은 임시 슬라이딩 도형이다. 실제 경첩 문과 애니메이션은 후속 교체한다.
귀신은 임시 도형이며, 방 안으로 들어가면 짧은 예고 후 정해진 복도 경로로 접근한다. 범용 NavMesh 추격 AI는 아직 아니다.
UV 표시는 벽의 임시 영어 TextRender이며 조사 내용은 한국어로 제공한다. 대상에 E를 눌러 읽은 자료가 발견 기록에 남는다.
문서 읽기 중 사건 시간과 UV 소모를 정지한다. 읽기 속도 때문에 자원을 잃지 않게 하는 첫 검증용 정책이다.
첫 민서 조사는 실제 NPC 대화 애니메이션 대신 문 너머 텍스트다.
‘이 규칙은 거짓말입니다’는 조사 화면에 나타나며 벽에 번지는 효과는 아직 없다.

## 완료한 오프라인 확인

Blender 5.2.2에서 원본 저장·FBX 6종 내보내기·프리뷰 렌더 성공.
합성 효과음 3종 생성 성공. Python 스크립트 구문과 JSON/FBX/WAV 무결성 확인 성공.
VS2022의 실제 C++ 컴파일러로 공통 메커닉 테스트 실행: 일반광 잔량 보존, UV 소모/소진, 중복 획득 방지, 초기 목격 시작/끝 경계 통과.

이 결과는 Unreal 프로젝트 컴파일·실행 검증을 대신하지 않는다. 그 결과는 실제 시도 후 이 문서에 추가한다.

## 출시를 위한 후속 작업

실행 검증 → 동선/공포/플레이타임 테스트 → 경첩 문·귀신 메시·공간 아트 → DAY 1 마무리 → DAY 2~5.
Steam SDK·스토어 페이지·현지화·설정/접근성·저장/클라우드·출시 QA는 별도 출시 단계에서 처리한다.
Fab 에셋 구매는 현재 불필요. AI 생성 콘텐츠를 실제 빌드에 추가하는 시점에 출처/권리/Disclosure 기록을 시작한다.

## 실제 엔진 검증 결과

Unreal 5.8.3 Editor 컴파일 성공, 생성 FBX 6종 및 WAV 3종 가져오기 성공. Windows Development 패키징 성공.
에디터 게임 모드와 패키징된 실행 파일의 `-NRSmokeTest`에서 각각 15개 검사 통과, `failures=0`.
일반 게임 렌더 실행 및 스크린샷 저장 성공. 한글 장비 UI와 가져온 전화기 메시를 시각적으로 확인했다.
자동 테스트는 직접 상호작용 함수를 호출하므로 키보드 조작, 계단 이동, 추격의 체감 난도, 모든 조사 순서에 대한 수동 플레이 검증을 대신하지 않는다.

### 환경 재질 1차 적용

`tools/create_environment.py`는 Blender로 CRT 모니터와 형광등을 포함한 환경 소품을 만든다. `tools/import_unreal.py`가 `Art/Textures`의 생성 이미지 두 장을 임포트하고 월드 좌표 기반 벽지·장판 재질을 생성한다. 천장은 별도 도장 재질을 사용한다. 원본 모델은 `Art/Generated/haedam_environment.blend`에서 직접 수정할 수 있다.

이 단계는 단순 도형에서 고시원 재질과 생활 소품을 추가한 첫 시각 개선이다. 귀신 모델, 침대, 문 여닫기, 생활 흔적과 최종 조명은 여전히 추가 작업이 필요하다.

### 2026-10-09 이동 및 관리실 창 수정

에디터 설정 변경과 무관하게 기본 PlayerInput/InputComponent를 사용하는 컨트롤러와 플레이어를 지정했다. 시작 안내는 이동을 막는 문서 대신 짧은 화면 메시지로 표시한다. 관리실 정면은 하부 130cm 벽과 상부 유리창으로 변경하고 책상 폭을 줄여 우측 통로를 확보했다.

Windows 패키지 빌드 성공. InputSmokeTest에서 시작 이동 허용, 입력 클래스, 이동 입력 수용, 시작 위치의 캡슐 이동을 포함해 20개 검사 통과. 실제 키보드 조작 체감과 옆문 통과 동선은 추가 플레이 확인 대상이다.

### 실제 WASD 이동 수정

이전 검사에는 이동 모드가 빠져 있었다. 뷰포트 키 이벤트 검사에서 입력 축 값은 정상인데 CharacterMovement 모드가 MOVE_None인 상태를 재현했다. 시작 위치 설정 후 MOVE_Walking을 지정해 해결했다. HUD는 HitTestInvisible로 설정해 화면 클릭을 가로채지 않도록 했다.

NRKeyTest는 이동 함수를 직접 호출하지 않고 게임 뷰포트에 W/S/A/D 눌림·해제 이벤트를 전달한다. 에디터 실행에서 각 방향 실제 변위 약 120/120/84/84cm로 모두 통과했다. 명령줄 -NRKeyTest로 재검사할 수 있다.

### 출입구 및 외부 창문

Blender에서 분리된 프레임·유리·손잡이를 가진 SM_EntranceDoor를 제작했다. 관리실 맞은편 현관은 E로 여닫을 수 있고, 문을 열면 외부 바닥으로 걸어나갈 수 있다. 외부에는 제한된 야간 골목, 인접 건물, 가로등과 하늘을 추가했다. 2층 복도 끝 및 202·203호 외벽을 실제로 비워 창문을 설치했다.

외부 건물과 골목은 아직 기본 형태이며 완성된 출시용 환경은 아니다. 새 재질은 Unreal의 절차적 색상 재질이고 추가 외부 이미지 생성물은 없다. Blender 원본은 Art/Generated/haedam_entrance.blend에 있다.

### 연결된 두 층과 생활공간

1층과 2층의 주 복도·뒤쪽 복도·좌측 통로·관리실 옆 통로·공용주방·휴게공간을 실제 보행 경로로 연결했다. 관리실 옆문은 연속되는 벽에 설치하고 이전 전실을 제거했다. 복도 폭은 4m로 시험하며, 실내 축척은 후속 플레이 평가로 조정한다.

새 Blender 원본은 haedam_furnishings.blend와 haedam_sanitary.blend이다. 냉장고, 전자레인지, 조리대, 식탁, 침대, 수납장, 세면대, 변기를 직접 생성했다. 귀신 경로는 가시성 기반 연결점 그래프를 사용하고 구형 스윕으로 벽·문을 검사한다. 202호를 나서는 순간 추격이 종료되던 조건을 제거했다.

NRMapTest는 W 키 이벤트와 실제 CharacterMovement로 관리실→연결통로→뒤쪽 복도→주방→계단→2층→202호의 12개 지점을 보행한다. 에디터 실행에서 모두 통과했다. NPC, 음식·식기, 최종 미술과 귀신 모델은 이 평면 검증과 별도로 보강해야 한다.

Windows 패키지에서도 NRMapTest(12지점), NRChaseTest(귀신이 뒤쪽 복도로 추격), NRExitTest, NRKeyTest, NRSmokeTest(20개)의 정상 종료를 확인했다. 가전제품 방향은 실제 주방 렌더에서 보정 확인했다. 프리뷰는 Art/Previews에 보관한다.

### 2026-10-09 CCTV·문서·카트리지 배치 수정

관리실 카트리지가 축소된 책상 밖에 있었고, 뒤편 예비 카트리지 두 개에는 받침대가 없었다. 관리실 책상 안쪽, 청소용품 선반 상판, 공구함 뚜껑으로 옮기고 실제 메시 경계의 높이로 배치한다. 위치는 줍기·체크포인트 복원 시에도 유지된다.

CCTV는 독립된 두 카메라 영상을 사용한다. 1층 출입 복도와 202·203호 앞을 표시하며, 관리실의 물리 모니터에도 2층 영상을 연결한다. PC 모니터에는 원래 스토리 데이터로 렌더한 입주자 명단을 표시한다. CRT의 방향과 별도 화면 평면을 보정했다. 고정 문구로 귀신이나 문 상태를 단정하던 설명을 제거하고 현재 영상과 시간에 따른 감지 기록을 구분한다. 녹화 파일 재생은 아직 미구현이다.

문서 패널은 1040×630 기준으로 화면에 맞게 확대·축소하고 스크롤을 지원한다. 발견 기록은 100자 단위로 자르지 않고 전체 내용을 표시한다. Esc로 닫으면 게임 입력으로 복귀한다. 읽는 동안 사건·UV 시간은 정지하며, 붉은 글씨는 별도 붉은 텍스트로 표시한다. 짧은 안내는 문서 패널과 겹치지 않고 만료된다. 전화벨 발생 위치도 관리실 전화기 위치로 수정했다.

Windows 빌드에서 NRPresentationTest 15개(받침 접촉, 모니터 재질, 사건 전후 CCTV 기록, 입력 복귀, 전문 기록 등), NRSmokeTest 20개, NRKeyTest 네 방향 이동이 통과했다. Art/Previews/NRCCTVPreview.png, NRMessagePreview.png, NRDeskPreview.png는 1280×720 실제 실행 캡처다. 외부 에셋 라이선스 변경이나 신규 AI 생성은 없다.

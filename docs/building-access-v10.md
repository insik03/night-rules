# 출입문·관리실 구조 수정 v10

2026-10-12. 사용자가 조감도의 1층 공용공간 출입문 누락, 기존 관리실과 다른 형태, 상층 수납방 진입 불가를 지적했다. 기존 평면에는 주방·화장실·샤워실 출입 표시가 있었으나 AI 조감도에 충실하게 반영되지 않았고, 왼쪽 옆 수납방의 연결문은 평면에도 없었다.

## 변경한 설계

- 각 층 주방·화장실·샤워실은 각각 주 복도와 직접 연결되는 90cm 문을 둔다. 이번 값은 계획 개구 폭이며 문틀/충돌 적용 후 유효 통과 폭을 확인한다. 실내로 열어 좁은 복도를 막지 않는다. 상층 샤워실 입구에서 내부 통로로 돌아가는 여유도 실제 모델에서 확인한다.
- 1층 관리실은 현행 NRGame.cpp의 280×280cm 외곽, 전면 하부 벽 130cm/상부 유리, 오른쪽 87cm 문틀 개구, 전면 쪽 264×55cm 책상을 기준으로 한다. 책상 뒤 의자와 한 명이 누울 여유를 유지한다. 관리실 오른쪽 벽선은 후면 구획까지 이어지고 출입구가 움푹한 별도 알코브가 되지 않는다.
- 관리실 왼쪽 옆 수납방으로 통하는 연결문을 추가한다. 전면 책상 구간을 피한 왼쪽 벽에 배치하며 옆 수납방 쪽으로 열린다. 선반은 문 회전과 통행을 막지 않도록 추후 배치한다.
- 2·3층 동일 위치는 기존 설정대로 관리 수납실이다. 새로운 총무실 2개를 만드는 것이 아니다. 복도 → 짧은 옆 접근 공간 → 관리 수납실 → 왼쪽 연결문 → 옆 수납방으로 접근한다. 두 문은 각각 안쪽 목적 공간으로 열린다.
- 뒤쪽의 큰 창고·설비실은 옆 접근 공간 끝에서 들어가는 막힌 방이다. 방을 통과해 두 번째 평행 복도로 이어지는 구조가 아니다.
- 새 방이나 면적을 추가하지 않는다. 좁은 주 복도, 원형 식탁 2개, 화장실/샤워실 분리, 202·307 공실/203 거주, 3층 리모델링 마감은 유지한다.

## 시안과 상태

`Art/EnvironmentConcepts/v10-access/proposed-*.png`는 좌표로 그린 도식이다. 민트 화살표는 진입, 노란 원호는 문짝 회전이다. `docs/floor-plan.html`에서 층별로 확인한다. 기존 v8/v9 조감도는 재질·분위기 참고로만 사용하며 출입구와 관리실 형상은 이 평면이 우선한다. 전체 조감도가 정확히 수정된 것으로 표현하지 않는다.

실제 게임 맵·충돌·Meshy 모델은 아직 변경하지 않았다. Meshy 생성/크레딧 사용 없음. 이후 모델 제작 시 개구부를 벽과 분리하고, 복도에서 공용공간과 옆 수납방까지 실제 보행을 검증해야 한다.

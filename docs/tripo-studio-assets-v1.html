배치와 개폐를 지킬 기준

  • 변기는 코드처럼 내부 통로(+Y)를 바라보고, 세면대는 오른쪽(+X)을 바라본다. 세면대의55×60은 제품 로컬 폭·깊이이며 배치 회전 후 바닥 점유는60×55가 된다. 도면의 단순 사각형과 구분한다.
  • 변기 뒤 외벽 중심선y=-900, 앞방향+Y. 제품 후면y=-875와 외벽 안쪽y=-892 사이17cm. 실제 반입 시 배관 접속을 검토한다.
  • 세면대 중심은 각 화장실 왼쪽 벽+60cm. 깊이60을 회전 적용하면 벽 내면과 후면 사이24cm. 기존 중심을 보존한 값이며 실제 벽밀착 위치/배관은 후속 확정이다.
  • 옥상 세탁기는 전면 도어 앞 최소90cm, 수납장은39cm 문짝 회전 반경과 통행 공간을 확보한다. 이 값은 설계 기준이며 Unreal 충돌 통과 보고가 아니다.
  • 1·2층과3층은 같은 메시를 쓰고 마모/색상만 바꾼다. 관리실·객실 옷장 크기와 배치를 이번에 바꾸지 않았다.
현재 Studio 패널의 공개 옵션은 ‘공유 전용’으로 표시됐다. 미리보기와 원본을 아직 업로드하지 않았으며, 실제 생성 전 공개 범위를 함께 확인해야 한다. 이 페이지는 생성 승인 요청을 위한 검토 자료다.

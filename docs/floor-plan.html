확대는 위 전체 도면의 동일한 도형을 확대합니다. 가구에 마우스를 올리면 크기를 볼 수 있습니다. 길이 단위는 모두 cm입니다.

01 / 관리실 방향 확정

현관을 등지고 안쪽을 볼 때 왼쪽 창고, 오른쪽 관리실. 중앙 칸막이 유지. 앞쪽 작은 방 두 칸을 없앤 넓은 현관 홀과 양문을 반영했습니다.

CCTV는 아래 3대·위 2대. 모니터 1=관리실 / 2=1층 / 3=2층 / 4=3층 / 5=옥상계단. 층별 모니터에서 복도·주방만 전환합니다.

02 / 방마다 사용 흔적

층당 거주 5실 / 총15명. 거주실: 침구·책·슬리퍼. 옷장 두 개는 침대 발치에 나란히. 202·307호를 포함한 조사 공실은 빈 프레임과 책상만 유지합니다.

202호에는 사건용 의자만 추가. 좁은 방에 선풍기·가방 등 모든 소품을 일괄로 넣지 않습니다.

03 / 공용공간과 옥상

층별 원형 식탁2개. 싱크대·조리대는 출입구 반대쪽 벽. 변기와 샤워는 외벽을 등지고 내부 통로를 향합니다. 화장실 안에는 샤워가 없습니다.

3층은 깨끗한 리모델링 마감. 옥상은 빨랫줄·차양·세탁 공간. 계단과 복도 끝은 비워 둡니다.

치수 확인: 관리실은 최신 코드에서 465×420cm입니다. 초기의 아주 작은 관리실과는 크기가 다르지만, 이번 도면에서 임의로 줄이지 않았습니다. 원형 식탁도 현재 게임의 지름200cm를 유지했습니다. 건물 전체44m 길이와 큰 주방 역시 현행 코드 비율입니다.

생성 후 크기를 맞추는 기준

Tripo·Meshy 결과의 크기를 그대로 믿지 않고 Blender에서 위 치수로 맞춘 뒤 스케일을 적용합니다. Unreal은 1유닛=1cm 기준으로 가져옵니다. 문·서랍·옷장문·냉장고문은 본체와 분리하고 회전축·이동축을 잡습니다. 실제 메시의 최대 외형, 문 회전, 서랍을 연 상태, 플레이어 충돌체로 통행을 확인한 후 게임에 반영합니다.

점선 동선과 문 회전 표시는 배치 검토용입니다. 실제 경첩 방향과 충돌 검증을 완료했다는 의미는 아닙니다. 2·3층 창고 가구와 옥상 세탁 소품은 신규 제안입니다.

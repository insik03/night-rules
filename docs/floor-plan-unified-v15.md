# 해담고시원 통합 설계·가구 배치 v15

2026-11-01 보완: 외형·배치 좌표는 유지하고 [가구 개폐 검토 v2](furniture-review-v2.html)에서 옷장 문을 각21.5cm 양문으로 수정했다. 아래 90도 개방 불가 설명은 수정 전 단문 구조의 기록이다. v2 Blender 모델의 문–침대 여유는 최소 약19cm이며 게임 반입은 별도다.

2026-10-22. 현행 제작 기준은 [통합 설계도](floor-plan.html) 하나로 통일한다.

## 근거와 범위

- 구조·공간 좌표: `NRGame.h`의 NRLayout, `NRArchitecture.cpp`의 BuildArchitecture.
- 객실 점유·기존 가구 중심: `NRGame.cpp`의 Room / BuildWorld.
- 관리실 좌우 및 창틀: architecture-office-v5.md의 v5/v6. v3/v4와 초기 280×280cm 관리실 안은 제외.
- 이번 변경은 검토 도면과 가구 제작 명세다. Unreal 맵, 실행파일, Meshy/Tripo 생성 작업은 변경하지 않았다.
- 전체 도면과 확대는 같은 SVG를 사용한다. 새로 생성한 조감도를 별도 구조 기준으로 사용하지 않는다.

## 통합 내용

1. 3개 층과 옥상. 단일 복도, 객실 12개/층, 15개 거주실, 조사 공실 9개.
2. 1층 양문 현관, 전면 작은 방 제거. 기존 창고를 465×420cm씩 나누고 중앙 벽 유지. 현관을 등지고 실내를 볼 때 창고 왼쪽·관리실 오른쪽.
3. 1층 공용공간은 주방·화장실·샤워실, 2·3층은 주방·샤워실·화장실 순서. 공용공간별 독립 출입구.
4. 2·3층은 접근 공간→관리 수납실→옆 수납방. 후면 창고에는 접근 공간에서 별도 문으로 진입.
5. 원형 식탁 Ø200×75cm, 각 층2개. 객실 옷장45×45×175cm 두 개는 침대 발치에 2cm 간격으로 나란히. 발치 여유39.5cm이며 문90도 개방 시 침대와 간섭하므로 개방각/문 방식 검토 필요.
6. 202·307호 등 조사 공실에는 침대 프레임과 책상만 두고 202호 사건 의자 유지. 나머지 공실은 비움.
7. 위생기구는 외벽을 등지고 내부 통로를 향하게 표시. 샤워1층4칸, 상층각2칸. 각 층 변기3개.
8. 옥상 빨랫줄·차양은 코드 기준, 세탁기·빨래·건조대는 신규 제안. 서측 외부 계단은 현재 코드가 1~3층까지만 연결하므로 옥상 연결 출입구를 그리지 않음.

## 치수 사용 시 구분

공간은 벽 중심선 치수다. 객실230×300cm는 순수 실내 크기가 아니며, 복도130cm는 마감·벽 두께를 제외한 유효폭과 다르다. 일반 출입문87×205.5cm는 개구부다. 실제 문짝·문틀은 개구부 안에 맞춘다.

관리실4.65×4.2m, 전체44×11.3m, 1층 주방12.5×7m, 상층 주방17.45×7m는 현행 코드의 큰 비율을 숨기지 않고 명시했다. 초기의 작은 관리실 설명과 달라도 이번에 임의로 축소하지 않는다.

책상·식탁·옷장 등 확인 가능한 확정 치수 외에 침대, 객실 책상, 냉장고, 변기·세면대 외형 등은 생성·교체용 권장치다. 기존 FBX의 렌더링 경계를 실측한 것으로 표현하지 않는다. 새 의자는42×44×80cm, 침구88×195×18cm, 싱크대120×60×85cm를 제안한다.

문 회전 영역은 배치 검토용 개략 표시이며 런타임 경첩을 완전히 재현하지 않는다. 점선 이동 경로 역시 실제 충돌 검증 결과가 아니다. 의자 사용·옷장문 개방·침대 가장자리 동선은 메시 가져오기 후 검증한다.

## 재현과 파일

- `python tools/create_unified_furnished_plan.py`
- `Art/EnvironmentConcepts/unified-v15/floor-1.svg` ~ `floor-4.svg`
- `Art/EnvironmentConcepts/unified-v15/furniture-layout.json`: 배치 중심, 가구 외형 목표, 상태, 소스 SHA256.
- `docs/floor-plan.html`: 유일한 현행 설계 페이지. 과거 검토 페이지에는 이 페이지 안내를 추가한다.

새 생성·교체 소품은 녹색 점선, 기존 배치 기준 가구는 갈색 실선이다. 상부장·책은 바닥 점유 가구가 아니라 벽·상판 부착물이다. 프로토타입 소품의 위치를 보존하며 추가 소품은 진입 동선을 막지 않는 쪽으로 제안했다.

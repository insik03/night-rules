## 비율 검수

원본 GLB는 변경하지 않았다. 아래 수치는 Blender가 읽은 전체 외형 비율을 기준 축 하나에 맞춰 균일 환산한 참고치이며, 현재 파일의 물리 cm 단위가 아니다. 베개·이불·수도꼭지·호스 등 포함 여부에 유의한다.

- 철제·합판 의자: 높이80cm로 전체를 균일 환산하면 약49.5×54.3×80cm. 목표42×44보다 넓고 깊음. 치수 적합 판정 보류.
- 싱글 침구: 전체 길이195cm 기준 균일 환산하면 폭 약112.4cm. 목표 매트리스 폭88cm보다 넓음. 측정에 베개·이불 포함; 침대에 바로 맞는 상태 아님.
- 싱크대·하부장: 폭120cm 기준 전체 깊이 약60.1cm, 전체 높이 약89.0cm. 전체 높이는 수도꼭지 포함이라 상판 높이85cm 충족 여부는 별도 실측 필요. 문은 아직 본체와 미분리.
- 샤워 세트: 전체 높이110cm 기준 약32.2×19.0×110cm. 호스·레일 포함 전체 외형; 목표25×15 및 레일 길이는 별도 검수 필요.
- 슬리퍼 한 쌍: 한 쌍의 전체 길이28cm 기준 약24.4×28×6.9cm. 각 슬리퍼 치수는 분리 후 측정 필요. 두 슬리퍼는 현재 한 메시 오브젝트.
- 시험 준비용 책 묶음: 전체 폭30cm 기준 약30×21.9×19.2cm. 목표 높이25cm보다 낮음. 여러 책이 한 정적 메시 오브젝트.

## 파일

- 각 소품 폴더: model.glb / preview.png. references/: 생성 입력 이미지.
- delivery.json: 공개 가능한 task ID·비용·결과 파일 기록. geometry-audit.json: 원본 외형과 삼각형 수.
- meshy_output/ 및 원시 CLI 결과는 서명 URL을 포함할 수 있어 Git 제외.
- 일부 Meshy CLI 다운로드는 완료 JSON과 파일을 기록한 뒤 Windows libuv 종료 오류가 발생했다. 다운로드 완료 상태·실제 PNG와 GLB 헤더를 확인했으며 유료 작업을 재제출하지 않았다.

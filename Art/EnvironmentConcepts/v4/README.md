# 상층 확장 주방 · 식탁 3개

2026-10-12. 사용자 요청에 따른 평면/이미지 수정. 실제 게임이나 3D 모델 변경은 아님.

- `floor-2-expanded-kitchen.png`: 내장 image_gen으로 생성한 2층 검토용 조감도. 기존 재질/카메라를 참조하고 새 평면에 맞춰 하부 공간을 수정했다.
- `image-prompt.txt`: 이미지 생성 프롬프트 원문. 참조는 v4/proposed-2.png(배치 우선), v3/floor-2-concept.png(외형·시점).
- `proposed-1.png`: 1층 휴게공간 유지.
- `proposed-2.png`, `proposed-3.png`: 상층 휴게공간 제거, 화장실을 계단 쪽으로 이동, 확장 주방에 식탁 각 3개 배치. 조리대/싱크/냉장고는 주방 출입문 반대편 외벽에 두고 입구를 비운다.
- `proposed-roof.png`: 옥상 동선 유지.
- `current-*.png`: 게임에 아직 남아 있는 기존 배치 비교용.

상태는 pending_image_review. 생성 이미지의 의자 개수/문 세부는 정확한 모델 명세가 아니다. 평면의 좌석 계획은 식탁당 6석이며 생성 이미지에 추가 표현된 끝자리 의자는 확정하지 않았다. 실제 모델에서는 문이 열린 상태, 냉장고가 열린 상태, 의자를 뒤로 뺀 상태를 포함해 통로를 확인한다. v3 이미지는 사용자가 지적한 상층 휴게공간·식탁 부족·문 앞 가구 배치 때문에 대체되었다.

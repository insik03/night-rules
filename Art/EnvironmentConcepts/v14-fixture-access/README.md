# 단일 1층 시안 — 위생기구 방향·뒤 창고 진입 수정

2026-10-12. 사용자는 방 위치 교환이 아니라 변기·샤워부스의 바라보는 방향을 반대로 바꾸도록 명확히 답했다. 또한 관리실 뒤 창고에서 문을 열어도 안이 막힌 느낌을 수정하도록 요청했다.

내장 image_gen으로 v13 단일 원본을 수정했다. 첫 편집에 남은 샤워부스 앞쪽 설비 벽과 잘못 늘어난 변기 개수를 두 번째 편집에서 바로잡았다. 최종 이미지는 floor1-master.png 한 장이다.

- 화장실과 샤워실 방 위치 및 복도 출입문은 유지한다.
- 변기 3칸은 외벽 쪽에 등/물탱크를 두고 방 안쪽 통로를 향한다. 칸 문은 통로 쪽에서 열린다.
- 샤워부스 4칸은 수전과 설비를 외벽 쪽으로 옮기고, 앞쪽을 막던 설비 벽을 없애 실내 통로에서 들어가는 개방부를 보여준다.
- 뒤 창고는 문 안쪽 가벽/막힌 귀퉁이를 정리하고 선반을 왼쪽에 모아 입구부터 방 중심까지 빈 바닥이 이어지게 표현한다.
- 관리실 앞 작은 방 두 칸을 없앤 v13 변경과 단일 원본 확대 방식은 유지한다.

관리실·창고·위생공간 확대 버튼은 동일한 PNG를 스크롤/확대한다. 별도로 생성한 확대본은 사용하지 않는다. 실제 문 회전·통과 폭·충돌 및 설비 높이는 모델 단계에서 검증해야 한다. 이미지는 검토용이며 실제 게임 변경/Meshy 생성/크레딧 사용 없음.

2026-10-12. 사용자가 v11 확대 이미지의 현관·관리실 관계가 맞지 않음을 지적했다. 기존 확대 이미지의 현관이 별도 구획처럼 떨어져 있고 오른쪽 접근 통로로 돌아가는 연결이 불분명했다.

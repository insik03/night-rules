# 3층 화재 후 리모델링 시안

2026-10-12. 사용자가 화재 피해를 본 3층을 리모델링하여 깨끗하게 보이도록 제안했다. v8 조감도를 내장 image_gen으로 편집했다. 이미지 검토 단계이며 실제 게임 맵이나 Meshy 모델을 변경하지 않았다.

- 1·2층: 기존 낡은 벽지, 생활 흔적과 바닥 유지.
- 3층: 저렴하지만 깨끗한 미색 벽지, 밝은 회베이지 장판, 정돈한 문틀, 교체한 주방·욕실 타일. 고급 숙박시설로 바꾸지 않는다.
- 3층의 좁은 복도, 객실 구획, 가구 위치, 독립 샤워실과 화장실, 원형 식탁 2개는 유지한다. 307호 공실도 유지한다.
- 옥상·외부 비상계단은 기존 노후 상태를 유지한다.
- 깨끗함은 마감 상태의 차이다. 게임 조명 30% 감소 결정은 유지하며, 현재 이미지 자체가 실제 조명 밝기의 검증 자료는 아니다.
- 화재 흔적은 문틀 안쪽, 덧댄 벽의 이음부와 설비 뒤 등 보수에서 남은 부분에 제한하는 연출 제안이다. 사용자가 열고 조사할 때 확인하게 하며 자막으로 원인이나 정답을 단정하지 않는다.
- DAY 4의 3층 주방 조사와 310호 보수 명세를 이 외형 차이에 연결한다. 리모델링 시점·주체·은폐 의도는 이번 변경만으로 확정하지 않는다.

3층용 마감은 같은 구조의 재질 변형으로 제작할 계획이다. 이번 요청으로 Meshy 추가 생성 작업이나 추가 비용을 승인받은 것으로 취급하지 않는다. 이번 Meshy 크레딧 사용 없음.

생성 조감도는 분위기 참고용이다. 계단 연결 및 일부 위생기구 배치에 대한 v8의 제한은 여전히 유효하고 실제 치수·배치는 기존 층별 평면이 우선한다. 10종 모듈 시트의 낡은 재질은 1·2층용 참고이며 3층에 그대로 적용하지 않는다.

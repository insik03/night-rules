# Meshy 맵 제작 전 이미지 검토 v8

2026-10-12. 사용자 요청: 크레딧 사용 전 이미지부터 보여준다. Meshy 유료 작업은 제출하지 않았다.

## 이미지
- building-overview.png: 1~3층+옥상 전체 분위기/공간 구성 시안.
- module-kit.png: 건축 모듈 10종 외형 검토 시안.
- prompts.json: 내장 image_gen 생성 및 수정 프롬프트. 이전 실패 이미지들은 생성 도구 보관 위치에만 남겼다.

기준은 v7 원형 식탁 수정 이미지, v7 1층/옥상 평면, docs/building-layout-v6.md다. 좁은 한 줄 복도, 작은 방, 층마다 화장실과 별도 샤워실, 원형 식탁 2개, 작은 반벽·반유리 관리실/옆문, 옥상 빨래 공간을 유지한다. 202·307 공실, 203 거주실 유지.

## 비용
설치된 Meshy CLI 0.4.0의 make <image> --dry-run --output-schema v1 --format json --no-update-check 결과: 이미지→텍스처 포함 3D 1회 estimated_credits=30, requests_made=0.
10종 각 1회 = 약 300크레딧. 앞서 이야기한 11종 기준이면 330크레딧. 이번 시안에서는 10종으로 묶어 제안했다. 재생성·추가 유료 후처리·별도 소품 생성은 포함하지 않는다. 실제 청구는 작업 완료 후 consumed_credits로 확인해야 한다. 현재 잔액은 이 작업에서 조회하지 않았다.

## 모듈 10종 제안
01 복도 벽/빈 문틀, 02 창문 외벽, 03 작은 객실 골조, 04 관리실 반벽·유리 전면과 옆문, 05 주방 타일 골조, 06 화장실 칸막이, 07 샤워실 칸막이, 08 실내 계단, 09 외부 비상계단, 10 옥상 난간.

각 모듈은 반복 배치한다. 큰 조감도를 한 번에 Meshy에 넣어 게임 맵으로 쓰지 않는다. 제작 시 단일 모듈 이미지로 분리하고 문짝/유리/상호작용 파트는 분리한다. 기존 가구·문짝을 재사용한다. 층 슬래브·천장·충돌·맞물림은 Blender/Unreal에서 치수에 맞게 구성한다. 단순 벽이나 계단은 Blender 규격 제작이 더 안정적인 경우 유료 생성 수를 줄일 수 있다. 300은 현재 10회 생성안의 추정이지 반드시 소진해야 하는 금액이 아니다.

## 검토에서 확인한 제한
생성 이미지는 실제 게임 화면이나 정밀 도면이 아니다. 전체 시안의 계단과 일부 위생기구 배치는 정확한 제작 기준으로 삼을 수 없다. 모듈 시트 08은 수정 후에도 상부 계단의 귀환 경로가 명확하지 않아 재질/외형 참고로만 사용한다. 실제 생성에 앞서 두 개의 반층 계단과 계단참을 갖는 꺾임 계단 단면을 따로 확인해야 한다. 계단 이미지를 그대로 승인된 입력으로 취급하지 않는다. 실별 개수·입주 여부·문 위치·보행 폭은 기존 좌표 평면이 우선한다.

사용자 이미지 검토 전에는 Meshy 업로드/생성, 기존 맵 교체, 크레딧 소비를 진행하지 않는다.

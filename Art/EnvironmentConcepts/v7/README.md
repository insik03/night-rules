# 사용자 선택 기준 이미지 · 원형 식탁

2026-10-12. 사용자가 첨부한 조감도를 기준으로 지정하고 식탁을 원형으로 바꾸도록 요청했다.

- `user-selected-baseline.png`: 사용자 첨부 원본을 프로젝트 안에 보관. 선택된 공간/재질 기준이며 임시 폴더에만 의존하지 않는다.
- `floor-2-round-tables.png`: 내장 image_gen으로 원형 식탁 두 개와 주변 의자만 수정한 검토 이미지. `round-tables-prompt.txt`가 전체 프롬프트다.
- `proposed-*.png`: 각 층 평면의 식탁도 원형 2개로 변경. 지름 150cm, 좌석6개는 이미지/동선 검토용 초기값이다. 실측 및 모델 충돌 검증 전 확정값이 아니다.
- `current-*.png`: 실제 게임에 남은 기존 배치 비교용이며 수정하지 않았다.

선택된 이미지의 방/복도/분리 샤워실/화장실/계단/조리대 배치를 존중한다. 1층의 공간 배분은 기존 별도 설계를 유지하며 2층 이미지로 무단 통일하지 않는다. 생성 이미지에 표현된 소품 개수나 미세 치수는 실제 좌표 도면을 대체하지 않는다.

원형 테이블 수정본은 pending_image_review. 실제 게임 적용이나 Meshy 모델 생성은 아직 수행하지 않았다. 사칭 귀신 사건 초안은 `docs/event-door-impostor.md`에 추가했다.

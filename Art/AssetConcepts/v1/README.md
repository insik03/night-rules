# 해담고시원 환경·소품 이미지 후보 v1

2026-10-12. 내장 image_gen 도구로 생성한 외형 검토 이미지 7장, 66개 항목. 여러 개의 작은 물건을 묶은 항목을 포함한다. 새 NPC/귀신 디자인은 이번 범위가 아니다.

## 상태
- 사용자 외형 선택 전. Meshy 작업이나 유료 3D 생성은 실행하지 않았다.
- 런타임 및 맵 구조를 변경하지 않았다.
- 모음 시트는 Meshy에 직접 넣는 단일 자산 레퍼런스가 아니다. 승인된 물건을 개별 이미지로 준비한 뒤 생성한다.
- 종전 모델·이미지를 대체하지 않는다. 크기와 문 가동 범위는 평면/상호작용 설계를 따른다.
- 전체 프롬프트, 원본 경로, 항목 설명은 manifest.json에 보관한다.
- 원형 식탁 각 층 2개, 별도 샤워실, 관리실 반유리와 옆문, 공실 빈 프레임을 유지한다.

## 검토 메모
- 66개는 메시 개수가 아니라 검토 항목 수다. 재사용 소품, 여러 물건을 모은 세트, 건축 모듈을 포함한다.
- 생성 이미지를 직접 확인했다. 가구 내부와 열림 변형, 원형 식탁, 별도 욕실 설비, 관리실 반유리 구성이 표현되었다.
- 기계 구조는 이미지로 검증되지 않는다. O06 녹화기 트레이는 최종 하드디스크 구조로 확정하지 않는다.
- I01/I02는 외형 제안이며 기존 게임 카트리지와 맞는 결합 규격은 후속 모델링에서 정한다.
- B01은 개방 외형 예시이며 대화 시 8~12cm 초기 틈 제안과 암흑 내부 규칙을 우선한다.
- B02 체인 체결부, B10 계단 층고·발판·난간, 창문과 문틀 접합은 후속 실제 크기 검증 대상이다.
- 세탁기/녹음기 등은 배경·사건 소품 후보이며 새로운 미니게임이나 시스템을 자동으로 추가하지 않는다.
- 조사지, 수칙, 명부의 읽을 수 있는 텍스트와 화면은 게임에서 별도 제작한다.

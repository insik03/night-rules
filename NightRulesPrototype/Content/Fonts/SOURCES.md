# Document fonts

Unmodified font binaries downloaded 2026-10-12 from the official Google Fonts repository.

- Nanum Myeongjo Regular / Bold: https://github.com/google/fonts/tree/main/ofl/nanummyeongjo
- Nanum Brush Script: https://github.com/google/fonts/tree/main/ofl/nanumbrushscript

Copyright notices and SIL OFL 1.1 are retained alongside each family. Files in this directory are staged as loose files with the game so the bundled licenses remain directly readable. Original font binaries are not modified. Generated document artwork is in Art/StoryProps; its provenance manifest records font SHA-256 hashes.

Both red-note writers use the same Nanum Brush Script font, size and ink colour. There is no author-specific handwriting or tint.
